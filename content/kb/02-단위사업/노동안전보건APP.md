# 노동안전보건APP

## 현행 목표

언제 어디서나 노동안전 정보를 확인하고 대처할 수 있는 APP. 1년차에는 기초 데이터 기반으로 **MSDS 정보 검색, 현장 상황 분석·위험도 측정** 등 핵심 기능이 작동하는 데모(MVP)를 제작한다. 감시용이 아니라 **노동자 스스로 위험을 포착하고 현장을 바꾸는 도구**.

## 활동 내용

| 활동 | 내용 |
|---|---|
| safefactory.kr 운영 | 반도체 교육자료 사이트. 학생용 반도체 교육자료 **챗봇(RAG)** 활성화 — 하반기 API 사용 증가 대비 |
| 반도체학습자료창고 | 학습자료 페이지 품질 향상 |
| 학습용 영상·이미지 제작 | 반도체고 교과서 기반. AI 생성 크레딧 활용 (영상 600,000 / 이미지·영상 1,444,588) |
| 챗봇 성능 향상 | 데이터베이스(pinecone) 성능·답변 API (270,000) |
| 애플개발자등록 | 129,000 |
| 데이터베이스 | MSDS 실시간 정보, 위험요소 요약, 산업안전 매뉴얼 학습 |

**제작 방식**: 대표가 직접 제작 (외부 자문 없음). 클로드코드·pinecone·Figma·미리캔버스로 제작-DB-배포를 일원화 (일반관리비).

## 일정

2026-02 ~ 11. 상반기: 서버·DB 구독, RAG 구축 (실적·집행 → `kb/09-성과실적.md#1/1.2`·`#3`). 하반기: API·생성 크레딧, 학습자료 제작, 챗봇 활성화. 4분기 MVP 시연.

## 대상

현장실습 예정 청소년, 반도체·제조업 현장 노동자, 전공교사 (학습자료·영상)

## 예산

`facts.units[id=app].budget` — 총 3,000,000원 (지급수수료 3,000,000). 사업인건비(자문) 0원.

## 성과지표

- MVP 시연 (시연 APP·기능 테스트 결과) — 4분기
- 학습용 영상·이미지 제작, 챗봇 활성화 (safefactory.kr)

## 향후 연결

2차년도 웹 APP 서비스 → 3차년도 네이티브 APP(android/iOS) 전환, 노동조합 안전담당자·명예산업안전감독관 배포. 장기적으로 현장 노하우·위험제보가 축적되는 "데이터 기반 노동안전보건 옴부즈만" 플랫폼.

## 홍보 포인트

- 교사에게: 수업에 바로 쓰는 반도체 학습자료·영상, 교과서 기반 챗봇
- 학생에게: 궁금한 걸 물어보면 답하는 반도체 안전 챗봇
- 시민에게: 청년노동자가 스스로를 지키는 도구를 단체가 직접 만든다

## 변경 배경 (1문단)

당초 외부 기술자문(사업인건비 1,000,000)을 받아 개발할 계획이었으나, AI 발전으로 자문 없이 프로토타입 제작이 가능해졌고 중간평가에서 대표가 직접 제작역량을 갖추는 것이 향후 커스터마이징·지속 운영에 더 중요하다고 판단해 자문을 편성하지 않았다. 대신 API 비용·학습자료 제작에 3,000,000원을 편성했다. `07-변경이력.md` §2.
