# 아름다운재단 수행가이드 — 홍보·표기·보고 관련 발췌

> 홍보물·문서를 만들 때 반드시 지키는 규정. 원문 쪽수는 PDF 기준.

## 1. 지원처 명기 (p.7~8, Ⅰ-6)

| 규정 | 적용 |
|---|---|
| 사업 관련 홍보자료·제작물에 **아름다운재단 지원을 필수 명기** | 모든 대외 산출물에 `credit_line` 또는 문장형 표기 |
| **'후원' 용어 금지 → '지원'** ("시민들이 후원한다기보다 '지지'한다는 의미") | `forbidden`: "아름다운재단 후원". 단, 우리 단체의 **후원회원·후원금**은 정상 용어 |
| 문장형 표기가 어려우면 **재단 로고만** 표기 가능. 로고 병기 시 **아름다운재단 로고가 앞** (단체 내부기준으로 순서 조정 가능) | 템플릿 하단 로고 행: [재단 로고][단체 로고] 순 |
| 리플릿·자료집 등에는 **아름다운재단과 지원사업 소개**를 넣을 것 | 리플릿 back 패널, 보고서 표지 뒷면에 소개 블록 |
| 홍보물 제작 시 재단 **CI/BI·사업 영역별 픽토그램** 활용 | 다운로드: 아름다운재단 ▶ 재단소개 ▶ CI/BI (https://beautifulfund.org/aboutus/cibi/) |
| **'아름다운재단'은 띄어쓰기 하지 않음** | `forbidden`: "아름다운 재단" |
| 지원처 명기 관련 **홍보물 제작·배포 전에 재단에 문의** | 체크리스트 final 단계: 재단 담당자 확인 |

### 표기 예시 (원문)

- 이 보고서는 [아름다운재단 로고] 지원으로 제작되었습니다.
- 이 행사는 [아름다운재단 로고] 지원으로 진행됩니다.
- 온라인 콘텐츠: "모두를 위한 변화 변화를 만드는 연결, 아름다운재단 ○○○○의 ○○○○사업"
- SNS 해시태그: #○○○○ #○○○○사업 #아름다운재단과 함께 #모두를위한변화 #변화를만드는연결
- 보도자료(검수 시 문장 제안): "○○사업은 아름다운재단과 함께 합니다. 아름다운재단은 모두를 위한 변화, 변화를 만드는 연결을 꿈꾸며 ○○사업을 추진합니다."

→ `facts.program.credit_sentences` / `hashtags`에 단체명을 채운 형태로 저장.

## 2. 홍보 의무 (p.7, Ⅰ-5)

- 자체 홍보채널로 지원사업을 적극 홍보하고 **내용을 재단 담당자에게 공유**
- 재단 블로그 공동 홍보 가능 — 재단 내부 일정 고려해 **1~2주 전 사전 요청**
- 보도자료 등 매체 홍보 필요 시 재단 홍보 담당부서와 협업 요청 가능
- 단체 자체 언론 홍보 시 **진행내용과 보도자료를 재단 담당자에게 사전 공유하고 재단 검수**
- 재단의 현장탐방·활동가/참여자 인터뷰·사진 촬영 요청에 협조

→ 보도자료 워크플로: 초안 → check → **재단 검수** → 배포. `templates/docs/보도자료.md` 상단에 명시.

## 3. 사업기간·보고 (p.6)

- 사업수행기간: 각 년차 1월 1일~12월 31일. 사업비 지출도 기간 내.
- 잔액 환급 12월 31일까지 (늦어도 2027-01-04)
- **결과보고서 2027-01-29까지** 제출. 사업기간 6개월 초과 시 중간점검(상반기 결과보고 기반 중간방문)
- 사업변경 신청은 **사업종료일 2개월 전(10-31)까지**. 결과보고 시 변경사항을 기록해야 함
- 대표자·소재지·법적지위·담당자 변경 시 재단에 통보

## 4. 홍보 관련 예산 계정 (p.28~29 계정항목 안내)

| 계정 | 관리그룹 | 범위 |
|---|---|---|
| 사업홍보비 | 사업비 | 단위사업 홍보, 사업참여자 모집 목적 — 홍보물 제작비, 언론/온라인 광고비 |
| 도서인쇄비 | 사업비 | 자료집, 교재 제본, 리플렛 등 인쇄물 제작비 |
| 지급수수료 | 사업비 | 외주용역 — 영상제작, 행사중계, 디자인, 통/번역, 연구조사, 장비임대 |
| 홍보비 | 운영비 | 단체 홍보, 회원모집, 회원활동 지원, 모금활동 목적 홍보비 |
| 일반관리비 | 운영비 | 소프트웨어 구독 등 취득단가 100만원 미만 |

사업인건비는 단체 내부인(대표·임원·급여 수령자·사업 담당자)에게 지급 불가.

## 5. 저작권·개인정보 (p.20~21)

- 지원금으로 제작한 도서·영상 등의 **저작권은 단체**에 있으며 판매도 가능 (계획서상 내용에 한함)
- 재단은 사업결과 홍보·기부자 보고를 위해 **출처를 밝히고 제작물을 공유·사용**할 수 있음 → 외주·저작권 계약 시 재단에 전시권·공중송신권 이용허락 조항 포함
- 외부 참석자 토론·강의자료는 재단 증빙 제출 사실을 안내하고 동의. 공개 가능/불가 자료 구분 고지
- 타인의 저작권·저작인접권 침해 주의 (사진·폰트·일러스트 라이선스 확인)
- 이력서·수령확인증 등 개인정보 수집 시 '개인정보 수집·이용 및 제3자 제공 동의서' 필요. 고유식별정보 처리 제한

→ 홍보물에 쓰는 사진: 참여자 초상 사용 동의 확인. 폰트: Pretendard(OFL) 사용.
