## Executive Summary

| Perspective | Content |
|-------------|---------|
| **Problem** | 사업 원천 문서 5건이 PDF 변환 마크다운으로 흩어져 있고(표 깨짐, 변경 전/후 수치 혼재, 개인정보 포함), 홍보물·보고서·제안서를 만들 때마다 문서를 다시 읽고 수치를 찾아 수작업으로 조립해야 함. 하반기 신설 활동(커피차 캠페인 3개교, AI학습동아리, '일하는 열아홉' 토론회 4회, 노동자종합지원센터 협력)마다 포스터·안내문·제안서가 즉시 필요 |
| **Solution** | ① 원천 문서 → **단일 진실 원천 `facts.yaml` + 주제별 kb 문서**로 정제(0823 변경 후 기준 고정, 변경이력 별도) ② **`/promo` 스킬**: brief → draft → visual → render 4단계 워크플로, 사실 검증·재단 표기·개인정보 마스킹 체크리스트 내장 ③ **HTML/CSS 템플릿 6종 + Playwright 렌더 스크립트**로 카드뉴스·포스터·리플릿을 PNG/PDF로 출력 ④ 문서류는 마크다운 초안 → 기존 `hwpx`/`docx` 스킬로 변환 |
| **Function/UX Effect** | `/promo brief "커피차 캠페인 포스터 인천"` 한 줄로 대상·목적·핵심 메시지·필수 표기가 담긴 브리프 생성 → 초안 → 이미지까지 10분 내 1차 산출물. 모든 산출물은 `content/out/날짜-슬러그/`에 brief·초안·최종본이 함께 보관되어 재활용·변형 가능 |
| **Core Value** | 1인 단체가 "문서 찾기 → 수치 확인 → 작성 → 디자인" 4단계를 "요청 → 검토"로 단축. 숫자·명칭·재단 표기 오류를 구조적으로 차단하고, 사업 변경이 생겨도 `facts.yaml` 하나만 갱신하면 이후 모든 산출물에 반영됨 |

### 1.2 문제점

1. **기준 시점 혼재**: 캠페인 30회(신청서) vs 3개교 각 1회(변경 후), 청소년참견위원회 5개교 vs AI학습동아리 1개교, APP 자문 유무 등 — 어느 문서를 읽느냐에 따라 다른 숫자가 나옴
2. **재사용 구조 없음**: 단체 소개·문제정의·성과지표 같은 반복 문구가 문서마다 조금씩 다르게 흩어져 있음
3. **개인정보**: 대표 이메일·휴대전화·직인 이미지가 원본에 포함 → 산출물·저장소에 유출 위험
4. **표 손상**: 예산 표가 마크다운으로 깨져 있어 그대로 인용 불가
5. **홍보물 디자인 자산 부재**: 뉴스레터 `community` 테마(Figma 디자인시스템 유래, `#0b98ff`/`#f9e450`/`#131313`)만 있고 포스터·카드뉴스용 템플릿 없음
6. **현재 사용 중인 도구와 단절**: 변경신청서에 명시된 제작 체계(클로드코드·Figma·미리캔버스)가 사업 데이터와 연결되어 있지 않음

### 1.3 활용 가능한 기존 자산

| 자산 | 위치 | 재사용 방식 |
|------|------|-------------|
| `hwpx` 스킬 (사용자 레벨) | `~/.claude/skills` | 마크다운 초안 → HWPX 공문·보고서 변환 |
| `document-skills:docx` / `pdf` | 플러그인 | DOCX 제안서, PDF 병합 |
| 뉴스레터 `community` 테마 | `index.html` `NL_THEMES.community` | 색상·타이포 토큰을 `brand/tokens.css`로 추출 |
| Playwright Chromium | `~/Library/Caches/ms-playwright/` (이미 설치) | HTML → PNG/PDF 렌더 |
| Apple SD Gothic Neo (시스템) | macOS | 폴백 폰트. 본문은 Pretendard(OFL) 동봉 |
| `docs/` PDCA 체계 | 본 저장소 | 본 기능도 동일 워크플로로 관리 |

## 2. 목표와 범위

### 2.1 목표

- 사업 문서에 근거한 **정확한** 텍스트·이미지 산출물을 **로컬에서 반복** 생산
- 사업 변경 시 **한 곳(`facts.yaml`)만 고치면** 이후 산출물이 모두 현행 기준을 따름
- 개인정보·재단 표기 규정 위반이 **산출물에 나가기 전에** 걸러짐

### 2.2 In Scope

- [ ] `content/kb/` 지식베이스 구축 (facts.yaml + 주제별 md 7종 + 변경이력)
- [ ] `content/brand/` 브랜드 킷 (색상·폰트·로고 슬롯·재단 표기 규정)
- [ ] `/promo` 스킬 (`.claude/skills/promo/SKILL.md`) — brief / draft / visual / render / kb-sync
- [ ] 문서 골격 템플릿 6종 (보고서·공문·협력제안서·보도자료·단체소개·안내문)
- [ ] 비주얼 HTML 템플릿 6종 (카드뉴스 1080², 인스타 4:5, OG 1200×630, A4 포스터, 3단 리플릿, 교사용 A4 안내문)
- [ ] `content/tools/render.py` — Playwright 기반 HTML → PNG/PDF
- [ ] 산출물 아카이브 규칙 (`content/out/YYYY-MM-DD-슬러그/`)
- [ ] 초기 산출물 카탈로그 12종 정의 (§5) 및 그중 4종 시범 제작으로 검증

### 2.3 Out of Scope

- AI 사진·일러스트 생성 (외부 이미지 생성 API 없음 — 사진은 `content/brand/photos/`에 수동 배치)
- `index.html` 앱 통합, Supabase 저장, Vercel 배포
- Figma MCP 연동 (후속 과제로 분리 — HTML 템플릿이 안정된 뒤 검토)
- 영상 제작, 미리캔버스 자동화
- 수행가이드 PDF 전문 구조화 (홍보 표기 규정·보고서 양식 관련 절만 추출)

| 단계 | 명령 | 입력 | 출력 | 내장 규칙 |
|------|------|------|------|-----------|
| 1 | `/promo brief <요청>` | 자연어 요청 | `out/…/brief.md` | 대상·목적·채널·규격·핵심메시지 3개·필수 표기(credit_line)·근거 kb 경로 명시. 모호하면 AskUserQuestion |
| 2 | `/promo draft` | brief | `draft.md` | facts.yaml만 수치 인용, 06-메시지 톤 적용, 대상별 어조, 분량 규격 준수 |
| 3 | `/promo visual <템플릿>` | draft + 템플릿 | `visual/*.html` | placeholder 치환, tokens.css 참조, 텍스트 넘침 시 자동 축약 제안 |
| 4 | `/promo render` | html | `final/*.png|pdf` | `tools/render.py` 실행, 결과 이미지를 Read로 확인 후 문제 있으면 3단계 재실행 |
| 문서 | `/promo doc <종류>` | brief | `draft.md` → `final/*.hwpx|docx` | `templates/docs/` 골격 → `hwpx`/`docx` 스킬 호출 |
| 검사 | `/promo check` | final | 검사 리포트 | `tools/check.py`: 수치 대조, 개인정보 패턴(전화·이메일·주민번호), 금칙어, credit_line 존재 |
| 동기화 | `/promo kb-sync <새 문서>` | data/ 신규 파일 | kb 갱신 + 07-변경이력 추가 | 변경 전/후 diff 표 생성, facts.yaml 변경 제안 후 사용자 승인 |

### 3.4 렌더 파이프라인

```
draft.md ─→ visual.html (tokens.css + Pretendard @font-face)
                │
                ▼  python3 content/tools/render.py visual/*.html --out final/ --scale 2
          Playwright Chromium (headless) ── document.fonts.ready 대기 ── screenshot(full) / pdf(A4)
                │
                ▼
          final/card-01.png … / poster.pdf  →  Claude가 Read로 시각 검토
```

- 카드뉴스: 페이지당 HTML 1개 → PNG 1개, 파일명 `card-01.png`부터 순번
- 인쇄물: `page.pdf(format='A4', printBackground=True)` + PNG 미리보기 동시 출력
- 폰트: `brand/fonts/`의 Pretendard woff2를 `@font-face`로 로컬 참조 (네트워크 불필요)
