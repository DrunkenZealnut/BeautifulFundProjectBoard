## 7. Match Rate 계산

- 축마다 항목 하나를 1로 세고 ✅=1, ⚠️=0.5, ❌=0. 이연(T6·T14)은 D에서 0으로 센다(충족하지 못한 증거).
- Check 1차 종합 = (A 55.5 + B 265 + C 34.5 + D 12) ÷ (56 + 273 + 40 + 14) = 367 ÷ 383 = **95.8%**.
- 같은 회차 수정 후 = (A 56 + B 273 + C 40 + D 12) ÷ 383 = 381 ÷ 383 = **99.5%**. 남은 2는 이연한 T6·T14다. A·B·C의 수정은 Check 2차(gap-detector C)가 15개 묶음 중 14개를 확인했고, Check 2차가 새로 지적한 4건(12장 기관명 서술, 서식 서버 안내, 오프라인 안내, 원문 표시 안내)은 메인 에이전트가 고친 뒤 검사·E2E로 확인했다
- 참고: bkit 기준(설계-구현 일치)만 보면 A+B = 320.5 ÷ 329 = 97.4% (Check 1차).
