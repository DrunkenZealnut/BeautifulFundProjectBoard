## 1. 무엇을 하는 시스템인가

아름다운재단 2026 공익단체 인큐베이팅 지원사업(1년차 7천만 원)의 예산 집행과 증빙, 정산·보고서, 사업 일정·기록·소식지를 한곳에서 관리하는 웹앱입니다. 재단 담당자도 계정으로 들어와 집행 현황을 봅니다.

| 메뉴 | 하는 일 | 주로 만드는 것 |
|---|---|---|
| 「🏠 대시보드」 | 예산·일정·게시글·사진 요약, 마감·미승인 집행·예산 소진 알림 | 인쇄본, HTML 스냅샷 |
| 「💰 예산관리」 | 집행 등록(한 건·일괄), 증빙 첨부, 상태 관리, 거래처 규칙, 원천징수 계산 | 정산보고서, 월별 명세서, 엑셀, HWPX 서식 |
| 「📅 일정관리」 | 사업 일정, Google 캘린더 연동 | — |
| 「📸 갤러리」 | 현장 사진·결과물 보관 | 사진 묶음(ZIP) |
| 「📋 게시판」 | 공지·자료·보고서·자유 글, 첨부파일, 댓글 | — |
| 「📖 회계가이드」 | 재단 회계 규정 요약, 원천징수 계산기, FAQ | — |
| 「📰 뉴스레터」 | 일정·게시글·사진으로 소식지 만들기 | HTML 파일, SNS용 복사본 |
| 「🏫 학교관리」 | 협력 학교 정보, 교과서, 시간표 조회 | — |
| 「⚙️ 관리자」 | 사용자·수급자·기관 정보·프로젝트·활동 로그 (관리자만 보임) | — |

돈이 나가는 일은 대부분 아래 흐름 하나로 이어집니다.

```
입금확인증 PDF·은행 엑셀 ─▶ 일괄등록 (자동배정·중복 표시) ─┐
영수증·세금계산서 ────────▶ 집행등록 (한 건) ──────────────┼─▶ 집행내역 (증빙 · 상태)
                                                            ┘      대기 → 승인 → 집행 → 완료
                                                                          │
                       대시보드·비용비율 ◀──────────────────────────────────┤
                       정산보고서 · 월별 명세서 · 엑셀 · HWPX 서식 ◀──────────┘
```

### 믿고 쓸 수 있게 하는 약속

1. **계좌번호를 집행 기록에 옮기지 않습니다** — 입금확인증 PDF의 계좌번호는 읽는 동안에만 쓰고 버립니다. 다만 증빙으로 붙는 PDF 원본에는 은행이 찍은 계좌번호가 그대로 있습니다.
2. **입금확인증은 이 컴퓨터 안에서 읽습니다** — 글자 추출은 브라우저에서 끝나고, 서버로 올라가는 것은 증빙으로 붙이는 PDF 파일뿐입니다.
3. **자동배정은 제안입니다** — 거래처 규칙과 과거 이력으로 예산 항목을 채워 주지만, 직접 고른 항목은 다시 덮어쓰지 않습니다.
4. **중복은 표시만 합니다** — 입금확인증이 이미 등록된 건과 같아 보이면 「⚠ 중복 의심」으로 표시하고 선택을 풀어 둡니다. 등록할지는 사람이 정합니다.
5. **보고서는 승인 이후 건만 셉니다** — 정산보고서·월별 명세서에는 「승인」「집행」「완료」 상태만 들어가고 「대기」는 빠집니다.
6. **증빙은 집행 건에 붙습니다** — 집행 유형마다 필요한 서류 목록을 보여 주고, 집행내역에서 건마다 첨부 상태를 확인합니다.
7. **비밀번호는 원문으로 저장하지 않습니다** — 서버에는 변환값(해시)만 남습니다.

## 2. 처음 준비

①~③은 처음에 한 번, ④~⑦은 그 기능을 쓰기 전에 한 번 하면 됩니다.

**① 로그인** — 관리자에게 받은 아이디와 비밀번호를 「아이디」「비밀번호」에 넣고 「로그인」을 누릅니다. 로그인은 24시간 유지되고, 지나면 로그인 화면이 다시 나옵니다. 「아이디 또는 비밀번호가 올바르지 않습니다.」가 나오면 입력을 확인하세요. 삭제된 계정은 로그인할 수 없습니다.

**② 프로필·비밀번호** — 오른쪽 위 내 이름을 누르면 「👤 프로필 수정」 창이 열립니다.
- 「이름」「이메일」「전화번호」를 고치고 「저장」을 누릅니다.
- 비밀번호를 바꿀 때만 「현재 비밀번호」「새 비밀번호」「새 비밀번호 확인」을 채웁니다. 새 비밀번호는 4자 이상이어야 하고, 입력하는 동안 강도(약함·보통·강함)가 표시됩니다.

**③ 지금 프로젝트 확인** — 화면 맨 위 제목이 지금 쓰고 있는 프로젝트 이름이고, 그 아래에 단체명과 총 예산이 나옵니다. 다른 연차나 사업으로 바꾸려면 「⚙️ 관리자」 → 「📂 프로젝트 관리」에서 바꿉니다([4.9.4](#494-프로젝트-관리)).

**④ 기관 정보** — 급여지급명세서·회의진행일지·사업변경신청서에 들어갈 기관명·대표자명·주소·고유번호·직인 이미지를 「⚙️ 관리자」 → 「🏢 기관 정보」에 넣습니다([4.9.3](#493-기관-정보)). 비어 있으면 HWPX 서식을 만들 때 「기관정보 설정으로 이동」이 뜹니다.

**⑤ 수급자** — 운영인건비를 받는 사람을 「📋 수급자 관리」에 등록해 두면 급여지급명세서에 생년월일·주소가 채워집니다([4.9.2](#492-수급자-관리)).

**⑥ Google 캘린더 (선택)** — 일정을 Google 캘린더와 맞추려면 「📅 일정관리」에서 「Google Calendar 연결」을 누릅니다([4.3](#43-일정관리)).

**⑦ 홈 화면에 추가 (선택)** — 휴대폰 브라우저 메뉴의 "홈 화면에 추가"를 쓰면 앱처럼 열 수 있습니다.

> 처음 쓰는 화면에서는 오른쪽 위 「❓ 도움말」을 누르세요. 그 화면의 설명이 바로 열립니다. 도움말 창의 「이 화면」은 지금 화면의 절로, 「목차」는 맨 앞 목차로 갑니다. 닫을 때는 「✕」나 Esc를 누릅니다.

## 3. 빠른 시작 — 한 달 집행 한 바퀴

계좌이체로 쓴 한 달 치 집행을 등록하고 명세서까지 뽑는 흐름입니다. 처음 한 번은 이 순서대로 따라 해 보세요.

**① 입금확인증 받기** — 신한은행 인터넷뱅킹에서 그달 이체한 건의 입금확인증을 PDF로 저장합니다. 여러 건을 한 파일로 받아도 됩니다.

**② 올리기** — 「💰 예산관리」 → 「📥 일괄등록」 → 「📄 입금확인증 PDF」 → 「파일 선택」. 확인증 한 쪽이 미리보기 표의 한 행이 되고, 수수료가 찍힌 쪽은 바로 아래에 「수수료」 행이 하나 더 생깁니다.

**③ 확인하기**
- 「⚠ 중복 의심 (기존 … · …)」이 붙은 행은 이미 등록된 건과 같아 보여 체크가 꺼져 있습니다. 새 건이 맞을 때만 체크를 켭니다.
- 「소분류」「예산항목」이 빈 행은 「🔗 규칙·이력으로 빈 항목 채우기」로 채우고, 남은 행은 직접 고릅니다. 직접 고르면 「규칙 저장」이 체크되어 다음부터 그 수취인은 자동으로 채워집니다. 한 번만 거래하는 곳이면 체크를 끕니다.

**④ 등록하기** — 「✅ …건 일괄 등록」을 누르고 확인합니다. 각 행에 그 쪽만 잘린 PDF가 이체 증빙으로 붙고, 모든 건은 「대기」 상태로 들어갑니다.

**⑤ 증빙 채우기** — 「📋 집행내역 보기」를 눌러 노란 줄 「증빙서류 미비 …건」을 확인하고, 건마다 「필요 증빙서류:」의 「📎 첨부하기」로 수령확인증·영수증 같은 나머지 서류를 붙입니다.

**⑥ 상태 올리기** — 확인이 끝난 건은 「✅ 승인」, 지급을 마쳤으면 「💼 집행완료」, 증빙까지 갖췄으면 「🏁 완료처리」를 누릅니다. 여러 건은 체크한 뒤 「일괄 승인」「일괄 집행」「일괄 완료」로 한 번에 바꿉니다.

**⑦ 확인·출력** — 「🏠 대시보드」에서 집행률과 알림을 보고, 월말에 「📋 집행내역」의 「📋 월별 명세서」 옆 「📥 PDF」(또는 「📄 한글」)로 그달 명세서를 만듭니다.

> 예시 — 9월에 ㈜가나다인쇄 330,000원(수수료 500원)과 다라마케이터링 120,000원을 이체했다면: 확인증 2쪽짜리 PDF를 올리면 본 행 2개와 수수료 행 1개가 생깁니다 → 거래처 규칙으로 항목이 채워지면 그대로 등록 → 수령확인증을 붙이고 → 세 건을 「일괄 승인」 → 「📋 월별 명세서」의 9월에 3건, 450,500원이 나옵니다.

영수증이나 카드 결제처럼 입금확인증이 없는 건은 「📝 집행등록」에서 한 건씩 넣고 증빙을 함께 붙입니다([4.2.3](#423-집행등록)).

## 4. 화면별 사용법

### 4.1 대시보드
<!-- src: renderDashboard, getDashboardAlerts -->

**언제 쓰나** — 로그인하면 처음 열리는 화면입니다. 예산이 얼마나 쓰였는지, 다가오는 일정·마감과 처리할 일이 무엇인지 한눈에 볼 때.

**순서**
1. 맨 위 「예산 집행률」에서 전체 집행 비율과 「…원 / …원」(집행액 / 총예산)을 봅니다.
2. 그 아래 알림을 🔴부터 처리합니다. 다 본 알림은 오른쪽 ×로 닫습니다.
3. 「카테고리별 집행 현황」과 「⚖️ 카테고리별 과부족 현황」에서 많이 쓴 소분류를 확인합니다.
4. 자세히 볼 내용은 요약 카드나 「전체보기」를 눌러 해당 화면으로 갑니다.
5. 재단에 보여 주거나 기록으로 남길 때는 「🖨️ 인쇄」나 「📸 HTML 스냅샷」을 누릅니다.

**알림 4종** — 🔴 긴급 → 🟠 주의 → 🔵 안내 순으로 5개까지 보입니다. 재단 마감 알림은 5개 안에 들지 않아도 늘 보입니다. 하나를 닫으면 다음 알림이 올라옵니다. 읽는 법은 [6장](#6-알림표시-읽는-법).

| 알림 | 뜨는 조건 | 색 |
|---|---|---|
| 일정 「[D-…] … (…)」 | 시작일이 오늘부터 7일 안. 당일은 D-Day로 표시 | 1일 이내 🔴 · 3일 이내 🟠 · 그 밖 🔵 |
| 「미승인 집행건 …건 처리 필요」 | 「대기」 상태 집행이 1건 이상 | 🟠 |
| 재단 마감 (예: 「사업변경신청 마감」) | 재단 마감 5건 가운데 30일 안에 있는 것. 당일은 D-Day로 표시 | 3일 이내 🔴 · 7일 이내 🟠 · 그 밖 🔵 |
| 「… 예산 소진율 …%」 | 소분류 집행률 85% 이상 | 95% 이상 🔴 · 그 밖 🟠 |

닫은 알림은 이 브라우저 탭을 닫을 때까지 다시 뜨지 않습니다. 새로고침해도 닫힌 채로 있고, 새 탭에서 열면 다시 보입니다.

**화면 요소**

| 요소 | 하는 일 |
|---|---|
| 「🖨️ 인쇄」 | 브라우저 인쇄 창을 엽니다. 메뉴·버튼은 빼고 인쇄됩니다. 인쇄 창에서 "PDF로 저장"을 고르면 PDF로 남습니다 |
| 「📸 HTML 스냅샷」 | 지금 대시보드를 `대시보드_스냅샷_날짜.html` 파일로 내려받습니다. 버튼만 빠지고 모양은 그대로입니다 |

- 성과지표의 「진행 횟수 / 30회」와 「네이티브 APP 출시」는 사업변경(2026-08-23) 전 기준입니다. 변경 후 캠페인은 커피차 3개교 각 1회입니다. 성과지표 값은 프로젝트와 상관없이 하나만 저장됩니다 → [13장](#13-현재-한계).
- 취소 상태 일정도 일정 알림과 「예정된 일정」에 나옵니다. 「미승인 집행건 …건 처리 필요」를 닫으면 같은 탭에서는 건수가 늘어도 다시 뜨지 않습니다.

#### 4.2.1 예산 대시보드
<!-- src: renderBudget#dashboard -->

**언제 쓰나** — 전체·상반기·하반기 예산 가운데 얼마를 썼고 얼마가 남았는지 확인할 때.

**순서**
1. 「💰 예산관리」에 처음 들어가면 이 탭이 열리고, 전체 기간이 선택돼 있습니다.
2. 오른쪽 위 기간 버튼이나 그 아래 기간 카드를 눌러 기간을 고릅니다.
3. 큰 막대에서 그 기간의 집행률을, 「사업별 집행률」에서 단위사업별 집행액과 잔액을 봅니다.

**화면 요소**

| 요소 | 하는 일 |
|---|---|
| 기간 버튼 | 전체·상반기·하반기 중 하나를 고릅니다. 이름은 프로젝트 설정을 따르며 기본은 「1차년도 전체」「상반기 (1~6월)」「하반기 (7~12월)」입니다 |

**주의**
- 집행액에는 「대기」 상태 건도 들어갑니다. 정산보고서·월별 명세서는 승인 이후 건만 세므로 금액이 다를 수 있습니다 → [4.2.7](#427-집행내역).
- 집행률은 100%에서 멈추고 잔액은 0원 아래로 내려가지 않습니다. 예산을 넘겨 썼는지는 「집행: …원」과 소분류 예산을 직접 비교하세요.
- 상반기·하반기는 집행일로 나눕니다. 나누는 날짜가 2026-01-01~2026-06-30, 2026-07-01~2026-12-31로 고정돼 있어 다른 연차 프로젝트에서는 반기 집계가 맞지 않습니다. 전체는 날짜와 상관없이 모든 집행을 더합니다.
- 고른 기간에 예산이 0원인 소분류는 「사업별 집행률」에 나오지 않습니다.

#### 4.2.2 예산편성표
<!-- src: renderBudget#breakdown -->

**언제 쓰나** — 편성된 금액과 산출근거, 상반기·하반기 배분을 확인할 때. 보기 전용 화면입니다.

**순서**
1. 「📋 예산편성표」 탭을 엽니다.
2. 위 요약표에서 사업비·운영비와 소분류별 전체·상반기·하반기 금액과 비중을 봅니다.
3. 기간 버튼을 고르면 아래 「… 상세 편성표」가 그 기간의 금액과 산출근거로 바뀝니다.

**화면 요소**

| 요소 | 하는 일 |
|---|---|
| 기간 버튼 | 「📊 대시보드」와 같은 버튼입니다. 여기서 바꾸면 대시보드도 같은 기간이 됩니다 |

- 앱 안에서 편성 구조를 바꾸는 길은 관리자 「📂 프로젝트 관리」의 「📥 엑셀 업로드」로 새 프로젝트를 만든 뒤 「활성화」하는 것뿐입니다 → [4.9.4](#494-프로젝트-관리).

**주의**
- 새 프로젝트를 활성화하면 그동안 등록한 집행은 옛 프로젝트에 남아 화면에서 빠집니다. 엑셀로 만든 프로젝트는 소분류·항목 번호도 새로 매겨져 기존 거래처 규칙이 연결되지 않습니다. 연중에 편성만 고치는 기능은 아직 없습니다 → [13장](#13-현재-한계).
- 「💾 현재 구조 저장」은 지금 화면의 편성이 아니라 앱에 처음부터 들어 있는 2026 편성으로 새 프로젝트를 만듭니다.

#### 4.2.3 집행등록
<!-- src: renderBudget#register -->

**언제 쓰나** — 집행 한 건을 직접 입력하고 증빙 파일을 함께 붙일 때. 입금확인증 PDF 한 장으로 입력을 채울 수도 있습니다.

**순서**
1. 입금확인증이 있으면 「📎 입금확인증 PDF로 자동입력」으로 PDF를 고릅니다. 「집행일」「집행 금액」「수취인」「집행 내용」이 채워지고 「결제 방법」이 「계좌이체」가 됩니다.
2. 「예산 분류」(대분류 > 소분류)와 「예산 항목」을 고릅니다. 「수취인」을 먼저 쓰면 입력란을 벗어날 때 거래처 규칙이나 과거 이력으로 둘 다 채워질 수 있습니다.
3. 「집행 금액」「결제 방법」「집행일」(처음엔 오늘)「수취인」「집행 내용」을 확인합니다.
4. 「예산 항목」과 「결제 방법」을 고르면 「📄 필요 증빙서류」가 나옵니다. 서류마다 「📎 첨부하기」로 파일을 고릅니다. 파일은 등록할 때 올라갑니다.
5. 「💾 등록하기」를 누릅니다. 「예산 집행이 성공적으로 등록되었습니다.」가 뜨면 끝입니다.
6. 자동입력한 PDF에 수수료가 있었다면 「이체수수료 …원을 같은 예산항목으로 추가 등록할까요?」가 이어서 뜹니다. "확인"을 누르면 수수료가 별도 건으로 등록됩니다.

> 예시 — ㈜가나다인쇄에 330,000원을 이체한 입금확인증(수수료 500원)으로 자동입력하고, 항목을 골라 등록한 뒤 수수료 확인창에서 "확인"을 누르면 두 건이 같은 항목으로 등록됩니다. 330,000원 건과 500원 건(수취인 「신한은행」, 집행 내용 「이체수수료 · …」)에 같은 PDF가 이체 증빙으로 붙습니다.

**화면 요소**

| 요소 | 하는 일 |
|---|---|
| 「예산 분류」「예산 항목」 | 소분류와 항목을 고릅니다. 항목 이름 옆 괄호가 계정이고, 계정에 따라 필요 증빙이 정해집니다 |
| 「📌 규칙」「🕘 이력 …회」「❓ 미배정」 | 「예산 분류」 옆 배지. 거래처 규칙으로 채움 / 같은 수취인의 과거 집행으로 채움 / 채우지 못함. 직접 고르면 사라집니다 |
| 「🕘 이력 후보 …개에서 선택…」 | 같은 수취인의 과거 항목 후보가 여럿이거나, 한 번뿐이라 자동으로 정하지 않았을 때 나옵니다. 고르면 그 항목으로 채웁니다 |
| 「…을(를) 이 항목 규칙으로 저장 (다음부터 자동 배정)」 | 체크한 채 등록하면 이 수취인에 이 항목을 쓰는 거래처 규칙이 저장됩니다 → [4.2.5](#425-거래처-규칙) |
| 「집행 금액」 | 숫자만 들어가고 쉼표는 자동으로 붙습니다 |
| 「결제 방법」 | 「카드」 또는 「계좌이체」 |
| 「수취인」 | 직접 쓰거나 등록된 수급자 목록에서 고릅니다. 수급자를 고르면 급여지급명세서에 정보가 채워집니다 |
| 「📎 자동입력됨: … → 등록 시 이체 증빙으로 첨부됩니다」 | 자동입력한 PDF. 수수료가 있으면 「수수료 …원 (등록 후 추가 등록 여부 확인)」이 붙습니다. 「해제」를 누르면 첨부를 취소합니다 |
| 「📄 필요 증빙서류」 | 계정별 필요 서류 목록. 파일을 고른 서류는 「✅ …」로 바뀝니다. 아래 「💡 …」는 계정별 유의사항 |
| 「💾 등록하기」 / 「🔄 초기화」 | 등록 / 입력과 고른 파일을 모두 지움 |

**주의**
- 필수는 「예산 분류」「예산 항목」「집행 금액」「결제 방법」「집행 내용」입니다. 하나라도 비면 「필수 필드를 모두 입력해주세요. (결제 방법 포함)」이 뜹니다. 「수취인」은 필수가 아니지만 비우면 자동배정과 규칙 저장을 못 합니다.
- 증빙 첨부가 일부 실패해도 집행은 등록됩니다. 「⚠️ 일부 서류 첨부 실패:」가 뜨면 「📋 집행내역」에서 다시 첨부하세요.
- 고른 파일을 바꾸거나 빼는 버튼은 없습니다(자동입력 PDF만 「해제」). 잘못 골랐으면 「🔄 초기화」 후 다시 입력하세요.
- 수취인이 있는 상태에서 항목을 직접 고르면 규칙 저장이 기본으로 체크됩니다. 한 번만 거래하는 곳이면 체크를 끄세요. 규칙으로 채운 항목을 이번 건만 바꿀 때는 체크가 꺼진 채로 나와 기존 규칙을 덮지 않습니다.
- 자동입력은 신한은행 입금확인증으로만 검증했습니다. 여러 쪽 PDF는 첫 쪽만 읽고 첫 쪽만 붙입니다(여러 건은 「📥 일괄등록」). 스캔본은 값을 읽지 못하고 증빙으로만 붙습니다.
- 계정이 「예비비」나 「임차료」인 항목은 필요 증빙 목록이 비어 나옵니다. 필요한 서류는 「📖 회계가이드」에서 확인하세요. 이때 자동입력한 PDF는 「이체확인증」이라는 이름으로 붙습니다.
- 수행가이드는 이체수수료를 그 지출이 속한 예산항목(또는 단위사업)으로 잡도록 안내합니다(p.13). 수수료를 같은 항목으로 등록하는 이유입니다.

#### 4.2.4 일괄등록
<!-- src: renderBudget#import -->

**언제 쓰나** — 은행 입금확인증 PDF나 거래내역 엑셀로 여러 건을 한 번에 등록할 때.

**순서 — 입금확인증 PDF**
1. 「📄 입금확인증 PDF」를 고르고 PDF를 끌어다 놓거나 「파일 선택」으로 올립니다. 여러 파일, 여러 쪽짜리 PDF 모두 됩니다(파일당 200쪽까지).
2. 미리보기 표에 확인증 한 쪽이 한 행으로 나옵니다. 수수료가 찍힌 쪽은 바로 아래에 「수수료」 행이 하나 더 생깁니다.
3. 「상태」 열의 경고 「⚠ …」와 「⚠ 중복 의심 (기존 … · …)」을 확인합니다. 중복 의심 행은 체크가 꺼진 채로 나옵니다.
4. 빈 「소분류」「예산항목」은 「🔗 규칙·이력으로 빈 항목 채우기」로 채우고, 남은 행은 직접 고릅니다.
5. 「✅ …건 일괄 등록」을 누르고 확인창 「…을 일괄 등록하시겠습니까?」에서 "확인"을 누릅니다. 각 행에 그 쪽만 잘린 PDF가 이체 증빙으로 붙습니다.
6. 완료 화면에서 「📋 집행내역 보기」로 가거나 「📥 추가 업로드」로 더 올립니다.

> 예시 — 3쪽짜리 PDF(1쪽 ㈜가나다인쇄 330,000원·수수료 500원, 2·3쪽 같은 날 다라마케이터링 120,000원씩, 적요만 다름)를 올리면 본 행 3개와 수수료 행 1개가 생깁니다. 1쪽 행과 그 수수료 행에는 `원본이름_p1.pdf`가 붙습니다. 그날 다라마케이터링 120,000원 건이 이미 1건 등록돼 있었다면 2·3쪽 중 한 행에만 중복 의심이 붙습니다.

**순서 — 은행 거래내역 엑셀**
1. 「📊 은행 거래내역 엑셀」 → 「파일 선택」으로 .xlsx·.xls·.csv 파일을 올립니다. 첫 번째 시트만 읽습니다.
2. 「열 매핑 설정」에서 「날짜」「금액」「입금/출금 구분」「입금자/출금자」에 맞는 열이 골라졌는지 확인합니다. 머리글 이름으로 자동으로 고르지만 틀릴 수 있습니다.
3. 「입금」 행은 지출이 아니므로 체크를 끕니다. 「출금」 행의 「소분류」「예산항목」「설명」「결제방법」을 정합니다.
4. 「✅ …건 일괄 등록」으로 등록합니다. 엑셀 행에는 증빙이 붙지 않습니다.

**화면 요소** — 미리보기 표

| 요소 | 하는 일 |
|---|---|
| 「📄 입금확인증 PDF」 / 「📊 은행 거래내역 엑셀」 | 소스를 고릅니다. 미리보기 중에 바꾸면 「현재 미리보기를 지우고 소스를 바꿀까요?」를 묻습니다 |
| 맨 앞 체크 | 등록할 행을 고릅니다. 머리 줄 체크는 전체 선택·해제. 꺼진 행은 흐리게 보입니다 |
| 「날짜」「금액 (실지급액)」「수취인」 | PDF 본 행은 표에서 바로 고칩니다. 수수료 행은 금액·수취인이 고정이고 날짜(「└ …」)는 본 행을 따라갑니다. 엑셀 행(「금액」「입출금자」)은 고칠 수 없습니다 |
| 「구분」 | 「출금」「입금」「수수료」 |
| 「소분류」「예산항목」 | 직접 고른 행은 자동배정이 다시 덮지 않습니다 |
| 「📌 규칙」「🕘 이력 …회」「❓ 미배정」 / 「후보 …개 ▾」 | 항목을 무엇으로 채웠는지 / 과거 항목 후보에서 고르기(후보가 여럿이거나 한 번뿐일 때) |
| 「규칙 저장」 | 체크한 채 등록하면 이 수취인의 거래처 규칙이 저장됩니다 → [4.2.5](#425-거래처-규칙) |
| 「상태」(PDF만) | 「📎 PDF …/…쪽」(붙을 쪽), 「🏦 …」(입금은행), 중복 의심, 경고. 수수료 행은 「본 행 항목 연동」 또는 「항목 직접 지정」 |
| 「← 다시 업로드」 | 묻지 않고 미리보기를 지운 뒤 처음으로 돌아갑니다 |

**주의**
- 신한은행 인터넷뱅킹 입금확인증만 검증했습니다. 다른 은행 PDF는 값이 비거나 틀릴 수 있고 「입금확인증 형식을 인식하지 못했습니다」「날짜 미인식」 같은 경고가 붙습니다. 스캔본은 「텍스트 없음(스캔본)」이 붙고 파일 전체가 한 행이 됩니다. 여러 쪽 PDF에서 확인증이 아닌 쪽은 건너뛰고 안내창으로 알려 줍니다.
- 중복은 집행일·금액·수취인이 같은 기존 집행과 1:1로 짝지어 판정합니다. 같은 날 같은 금액을 같은 곳에 여러 번 보냈다면 이미 등록된 건수만큼만 중복 의심이 붙습니다(적요가 같은 행이 먼저). 같은 쪽을 두 번 올리면 「업로드 내 중복」. 표시만 하므로 새 건이 맞으면 체크를 켜고 등록하세요. PDF 행의 날짜·금액·수취인·설명을 고치면 다시 판정합니다(체크는 그대로).
- 엑셀 행은 중복 검사도, 날짜·금액 검사도 하지 않습니다. 이미 등록한 거래나 금액이 0인 행은 체크를 끄세요. 날짜가 빈 행은 오늘 날짜로 등록됩니다.
- 「입금/출금 구분」 열을 고르면 값에 출금·지급·이체가 들어간 행만 「출금」으로 보고, 「입금」 행은 자동배정하지 않습니다. 출금액과 입금액이 다른 열로 나뉜 엑셀이면 「금액」에 출금 열을 고르고 구분은 비워 두세요. 이때는 모든 행이 「입금」으로 보이고 모든 행이 자동배정 대상이니, 입금 거래 행은 직접 체크를 끄세요.
- 수수료 행은 본 행 항목을 따라가고, 직접 바꾸면 연동이 풀립니다. 본 행 체크를 꺼도 수수료 행 체크는 그대로이니 함께 끄세요.
- 항목을 고르지 않은 행은 건너뜁니다(확인창에 「예산항목이 지정되지 않은 …건은 건너뜁니다.」). PDF 행에 날짜나 금액이 비면 「등록 오류: …」가 뜨고 한 건도 등록되지 않습니다.
- 계좌번호는 읽기만 하고 집행 기록에 넣지 않습니다. 증빙으로 붙는 PDF 원본에는 계좌번호가 그대로 있습니다. 등록한 건은 모두 「대기」 상태입니다.

#### 4.2.5 거래처 규칙
<!-- src: renderBudget#rules -->

**언제 쓰나** — 자주 거래하는 업체·수취인을 예산항목에 미리 연결해 두고, 집행등록·일괄등록에서 소분류·항목이 저절로 채워지게 할 때.

**순서**
1. 「+ 규칙 추가」를 누릅니다.
2. 「표시명 (거래처·수취인)」에 이름을 적고 「매칭 방식」을 고릅니다. 보통은 「이름 일치 (권장)」이면 됩니다.
3. 「소분류」와 「예산항목」을 고릅니다. 「결제방법 (선택)」과 「메모」는 필요할 때만 씁니다.
4. 「💾 저장」을 누릅니다. 다음 등록부터 적용됩니다.
5. 집행이 쌓였다면 아래 「🕘 이력에서 규칙 만들기 (…)」에서 후보를 체크하고 「선택 …건 규칙으로 저장」을 누릅니다. 규칙 여러 개가 한 번에 생깁니다.

> 예시 — 표시명에 ㈜가나다인쇄를 적으면 「매칭 키 (자동)」 칸에 가나다인쇄가 나옵니다. 은행 기록에 "가나다인쇄 주식회사"나 "(주) 가나다 인쇄"로 찍혀도 같은 거래처로 봅니다.

**화면 요소**

| 요소 | 하는 일 |
|---|---|
| 「매칭 방식」 | 「이름 일치 (권장)」은 정리한 이름(매칭 키)이 같을 때, 「이름 포함 (업체 표기가 자주 바뀔 때)」은 수취인 이름에 「포함할 이름」이 들어 있을 때 맞습니다. 「사업자번호」는 숫자 10자리 |
| 「매칭 키 (자동)」 | 이름 일치에서 실제로 비교하는 값. (주)·㈜·주식회사 같은 법인 표기와 공백·괄호·점을 빼고, 영문은 소문자로 바꿉니다 |
| 「결제방법 (선택)」 | 규칙으로 배정될 때 결제 방법도 채웁니다. 기본값은 「증빙에서 온 값 유지」 |
| 「규칙 목록 (…)」 | 켜진 규칙이 먼저, 「사용」(규칙으로 배정된 채 등록된 건수)이 많은 순. 행마다 「수정」「끄기」(꺼진 규칙은 흐리게 보이고 「켜기」로 되살림)「삭제」 |
| 「⚠ 항목 없음 (예산 변경됨)」 | 예산 구조가 바뀌어 연결된 항목이 사라진 규칙(빨간 줄). 배정에 쓰이지 않으니 「수정」으로 항목을 다시 고르세요 |
| 「🕘 이력에서 규칙 만들기 (…)」 | 같은 수취인에게 2번 이상, 80% 이상 같은 항목으로 집행한 경우를 후보로 보여 줍니다. 「집행」 건수와 「일치율」을 보고 체크하세요. 이미 규칙이 있는 수취인은 빠집니다 |

**주의**
- 배정 순서는 사업자번호 → 이름 일치 → 이름 포함(긴 이름 먼저) → 이력 → 미배정입니다. 이력은 같은 수취인에게 가장 많이 쓴 항목이 2회 이상이고 1위가 하나일 때만 채우고, 아니면 후보만 보여 줍니다.
- 사업자번호 규칙은 지금의 집행등록·일괄등록에서는 쓰이지 않습니다. 세금계산서·영수증 인식 기능이 생기면 적용됩니다.
- 「이름 포함」은 개인 이름에 쓰지 마세요(동명이인). 이름 일치 규칙은 표시명에서 매칭 키를 만들므로, 표시명을 고치면 맞는 대상도 바뀝니다.
- 규칙의 결제 방법은 집행등록에서는 결제 방법이 비어 있을 때만, 일괄등록에서는 엑셀 행에만 들어갑니다. 입금확인증 PDF 행은 「계좌이체」 그대로입니다.
- 같은 매칭 조건의 규칙은 꺼 둔 것까지 합쳐 하나만 둘 수 있습니다. 겹치면 「같은 매칭 조건의 규칙이 이미 있습니다.」가 뜨니, 목록에서 기존 규칙을 「켜기」나 「수정」하세요.
- 규칙은 만들 때의 활성 프로젝트에 속합니다. 다른 프로젝트로 바꾸면 그 프로젝트 규칙과 공통 규칙(활성 프로젝트 없이 만든 규칙)만 보입니다.
- 「⚠️ 규칙 테이블을 불러올 수 없습니다.」가 뜨면 규칙을 저장할 수 없고 이력 추천만 동작합니다. 개발 담당자에게 알리세요.
- 집행등록·일괄등록에서 「규칙 저장」을 체크해도 규칙이 생깁니다([4.2.3](#423-집행등록), [4.2.4](#424-일괄등록)).

#### 4.2.6 원천징수계산
<!-- src: renderBudget#calculator, calculateWithholdingTax -->

**언제 쓰나** — 강사료·회의참석수당·원고료처럼 개인에게 주는 기타소득의 원천징수세와 실지급액을 지급 전에 계산할 때. 소득 유형별 필요 증빙도 함께 봅니다.

**순서**
1. 「1인 계산」이나 「다인 일괄계산」을 고릅니다.
2. 「소득 유형」을 고릅니다. 아래 설명과 「📋 … - 필요 증빙서류」, 「⚠️ 지급 시 주의사항」이 그 유형으로 바뀝니다.
3. 1인은 「지급 금액 (원)」을 넣고 「📊 계산하기」를 누릅니다. 다인은 줄마다 이름과 지급금액을 넣고(줄 추가 「+ 추가」, 줄 삭제 「×」) 「📊 일괄 계산」을 누릅니다.
4. 「총 원천징수세:」와 「실수령액:」(다인은 「공제합계」와 「실지급액」)을 확인합니다. 새로 하려면 「🔄 초기화」를 누릅니다.

> 예시 — 강사료 210,000원: 소득세 16,800원 + 지방소득세 1,680원 = 18,480원, 실수령액 191,520원. 120,000원이면 「원천징수 없음」으로 나옵니다.

**계산 기준** — 소득 유형을 바꿔도 식은 같습니다. 필요경비 60%인 기타소득(지급액의 8.8%) 기준입니다.

| 단계 | 계산 |
|---|---|
| 과세 여부 | 지급액이 125,000원 이하면 세금 0원 |
| 소득세 | 지급액 × 8%, 1원 미만 버림 |
| 지방소득세 | 소득세 × 10%, 1원 미만 버림 |
| 실지급액 | 지급액 − 소득세 − 지방소득세 |

**화면 요소**

| 요소 | 하는 일 |
|---|---|
| 「소득 유형」 | 「강사료」「단순인건비」「회의참석수당 / 심사비 / 토론비 / 발제비」「원고료」. 설명·필요 증빙·주의사항만 바뀝니다 |
| 「다인 일괄계산」 결과 표 | 사람마다 따로 계산해 「합계」 줄로 더합니다. 총액에 8.8%를 한 번에 곱하면 1원 단위가 달라질 수 있어서입니다. 125,000원 이하인 줄은 연두색 |
| 「📖 원천징수란?」「🏛️ 신고 · 납부 안내」「✅ 원천징수 기준 요약」 | 계산 방법, 신고·납부 기한(지급한 달의 다음 달 10일), 기타소득지급명세서 안내 |

**주의**
- 상금(필요경비 80%, 4.4%)이나 필요경비가 없는 소득은 이 탭의 식과 다릅니다. 회계가이드 「💰 원천징수 계산기」에서 「필요경비율」을 골라 계산하세요([4.6](#46-회계가이드)).
- 일용직 형태의 단순인건비는 세법상 일용근로소득(수행가이드 p.26: 근로소득의 6%)일 수 있습니다. 이 탭은 기타소득 식으로만 계산하니 세무 확인을 받으세요.
- 125,000원 기준을 입력한 금액 한 건으로만 판단합니다. 같은 사람에게 같은 날 강사비와 회의참석비를 함께 주면 그 합계로 판단하니(수행가이드 p.14) 합계를 넣으세요.
- 「원천징수 없음」이어도 원천징수이행상황신고와 지급명세서 제출은 필요합니다(수행가이드 p.27).
- 계산 결과는 집행 기록에 저장되지 않습니다.

#### 4.2.7 집행내역
<!-- src: renderBudget#history -->

**언제 쓰나** — 등록한 집행을 찾아 고치고, 상태를 바꾸고, 빠진 증빙을 붙이고, 보고서·엑셀·재단 서식을 뽑을 때.

**순서**
1. 검색창(「🔍 항목명, 설명, 수취인 검색...」)과 필터로 건을 좁힙니다. 「📊 …건 / …건」은 찾은 건수 / 전체 건수입니다.
2. 노란 줄 「증빙서류 미비 …건」이 보이면 각 건의 「필요 증빙서류:」에서 「📎 첨부하기」로 파일을 붙입니다.
3. 틀린 내용은 「✏️ 수정」에서 고치고 「저장」을 누릅니다.
4. 상태를 올립니다. 관리자는 행마다 다음 단계 버튼 하나(대기 「✅ 승인」 → 승인 「💼 집행완료」 → 집행 「🏁 완료처리」)를 누르거나, 여러 건을 체크해 「일괄 승인」「일괄 집행」「일괄 완료」를 누릅니다.
5. 위쪽 버튼으로 보고서·엑셀을 뽑습니다(아래 출력 표, [8장](#8-내보내기출력물)).

**화면 요소**

| 요소 | 하는 일 |
|---|---|
| 「카테고리 전체」「소분류 전체」「상태 전체」「결제 전체」, 날짜 두 칸 | 카테고리 → 소분류(카테고리를 고른 뒤 열림), 상태 4단계, 「카드」/「계좌이체」, 집행일 기간(양 끝 포함). 검색은 항목명·설명·수취인만 봅니다 |
| 정렬 「집행일」「금액」「등록일」, 「↓ 내림차순」/「↑ 오름차순」 | 처음에는 집행일 최신순. 「🔄 초기화」는 검색·필터·정렬과 체크를 모두 처음으로 돌립니다 |
| 「✏️ 수정」 | 「예산 분류」「예산 항목」「금액 (원)」「결제방법」「집행일」「수취인」「설명」「비고」를 고칩니다. 역할 제한 없음 |
| 「🗑️ 삭제」, 「✅ 승인」「💼 집행완료」「🏁 완료처리」 | 관리자에게만 보입니다. 삭제는 「정말 삭제하시겠습니까?」 → 「확인」 |
| 「필요 증빙서류:」 | 예산 항목 유형별 서류 목록. 붙은 서류는 「⬇️ …」(내려받기), 없는 서류는 「📎 첨부하기」. 목록 밖 이름으로 붙은 파일은 「기타 첨부 증빙:」 아래에 |
| 「📄 급여지급명세서 생성」「📥 PDF」「📝 HWPX」 | 유형이 운영인건비이고 수취인이 있는 건에만 보입니다 |
| 「📋 회의진행일지 생성」 | 유형이 사업인건비·사업회의비·교육훈련비인 건. 창에서 「회의 제목」「일시」「장소」「회의 내용 / 안건」「참석자 명단」(한 줄에 한 명)을 넣습니다 |
| 「✅ …건 선택」 줄 | 체크하면 위에 뜹니다(「전체」는 보이는 건 모두 체크). 「일괄 승인」「일괄 집행」「일괄 완료」「📥 선택 내보내기」「🧾 영수증빙 HWPX」「일괄 삭제」「선택 해제」. 역할 제한 없음 |

**출력**

| 버튼 | 결과 | 범위 |
|---|---|---|
| 「📊 Excel 내보내기」 / 「📥 선택 내보내기」 | xlsx 파일 | 지금 필터·정렬 그대로, 대기 포함 / 체크한 건 중 보이는 건 |
| 「📄 정산보고서」「📥 PDF」「📄 한글」 | 새 창을 열고 인쇄 창 / PDF 파일 / 한글(HWPX) 파일 | 승인·집행·완료 전체(필터와 무관) |
| 「📋 월별 명세서」「📥 PDF」「📄 한글」 | 같은 세 형식, 달별로 묶고 소계 | 승인·집행·완료 전체 |
| 행의 「📄 급여지급명세서 생성」「📥 PDF」「📝 HWPX」 | 새 창 문서 / PDF 파일 / 미리보기 → 「📥 생성 및 다운로드」(지급 12건마다 1장, 여러 장이면 ZIP) | 그 수취인의 운영인건비 전체(상태 무관) |
| 「📦 급여명세서 일괄」 | 수취인마다 급여지급명세서 HTML 파일 1개를 묶은 ZIP | 운영인건비 전체(상태 무관) |
| 「🧾 영수증빙 HWPX」 | 미리보기에서 「시작 영수번호」를 정하고 「📥 생성 및 다운로드」. 재단 서식 1장에 2건(집행일순), 여러 장이면 ZIP. 한 번에 100장(200건)까지 | 체크한 건 중 보이는 승인·집행·완료 건 |
| 회의진행일지 창의 「📝 HWPX 다운로드」 / 「📋 문서 생성」 | 재단 서식 한글 파일(참석자 6명마다 1장, 여러 장이면 ZIP) / 새 창 인쇄용 문서(인원 제한 없음) | 창에 넣은 내용 |

> 예시 — 9월에 다라마케이터링 330,000원(승인)과 ㈜가나다인쇄 550,000원(대기)을 등록했다면, 「📋 월별 명세서」의 9월에는 330,000원 1건만 나오고 「📊 Excel 내보내기」에는 2건이 모두 나옵니다.

**주의**
- 엑셀 열은 집행일·대분류·소분류·항목명·유형·금액(원)·결제방법·수급자·상태입니다. 설명·비고는 들어가지 않습니다.
- 필터를 바꿔도 체크는 남습니다. 일괄 승인·집행·완료·삭제는 화면에서 가려진 체크 건에도 적용되고, 「📥 선택 내보내기」와 「🧾 영수증빙 HWPX」는 보이는 체크 건만 씁니다. 일괄 작업 전에 「✅ …건 선택」의 건수를 확인하세요.
- 일괄 상태 변경은 단계를 건너뛰거나 되돌릴 수 있습니다(대기 → 완료, 완료 → 승인). 대기로 되돌리는 버튼은 없습니다.
- 관리자가 아닌 계정도 일괄 승인·일괄 삭제와 수정을 할 수 있습니다([4.9.1](#491-사용자-관리)).
- 「✏️ 수정」에서 「예산 분류」를 바꾸면 「예산 항목」이 비워집니다. 항목을 다시 고른 뒤 저장하세요. 금액 칸을 비우고 저장하면 0원이 됩니다.
- 붙인 증빙을 바꾸거나 지우는 버튼은 없습니다.
- 증빙 목록은 결제 방법과 상관없이 같고, 대안 서류(카드 매출전표·세금계산서·계산서·현금영수증)와 해당할 때만 내는 서류까지 모두 나옵니다. 그래서 「증빙서류 미비 …건」은 실제보다 많을 수 있습니다. 증빙 규칙이 없는 유형(임차료·예비비)은 목록이 없고 미비 건수에도 들지 않습니다.
- 급여지급명세서는 그 수취인의 운영인건비 집행을 모두 모으고, 같은 날짜·같은 금액은 1건으로 칩니다. 생년월일·주소는 [4.9.2](#492-수급자-관리), 기관 칸은 [4.9.3](#493-기관-정보)에서 옵니다. 미리보기에 「기관정보 설정으로 이동」「수급자 관리로 이동」이 뜨면 그 칸이 빈칸으로 나옵니다.
- 정산보고서 표와 월별 명세서의 한 달 안 순서는 집행일순이 아니라 최근 등록순입니다.
- 「📄 정산보고서」「📋 월별 명세서」는 팝업이 막혀 있으면 아무 반응이 없습니다. 브라우저에서 이 사이트의 팝업을 허용하세요. 한글(HWPX) 파일은 서버에서 만들므로 인터넷 연결이 필요합니다.

#### 4.2.8 비용비율
<!-- src: renderBudget#ratio -->

**언제 쓰나** — 사업비·운영비 안에서 소분류와 세부 항목별로 예산을 얼마나 썼는지 막대로 비교할 때. 보기 전용 화면입니다.

**순서**
1. 기간을 바꾸려면 먼저 「📊 대시보드」 탭에서 기간 버튼(「1차년도 전체」「상반기 (1~6월)」「하반기 (7~12월)」)을 고릅니다. 이 탭에는 기간 버튼이 없습니다.
2. 「📊 비용비율」 탭에서 「💼 사업비」나 「🏢 운영비」를 고릅니다.

**화면 요소**

| 요소 | 하는 일 |
|---|---|
| 「… 전체 집행현황」 | 카테고리 집행률(%), 「집행:」「예산:」, 막대, 「잔액:」. 예산을 넘으면 「초과: …원」 |
| 소분류 카드 | 소분류 이름과 「예산 …원」, 큰 숫자 「집행률」, 막대, 「집행 …원」「잔액 …원」 |
| 「세부 항목」 | 항목마다 유형·예산, 집행률, 집행액 |
| 색 | 집행률 70% 이상 주황, 90% 이상 빨강. 소분류 잔액이 0원이면 잔액 숫자가 빨강 |

**주의**
- 대기 상태까지 더한 금액입니다. 승인 이후만 세는 정산보고서와 다를 수 있습니다.
- 집행률은 100%에서 멈춥니다. 넘은 금액은 「… 전체 집행현황」의 「초과: …원」에서만 보입니다.
- 상반기·하반기는 집행일로 나눕니다(2026-01-01~06-30, 2026-07-01~12-31). 집행일이 빈 건은 전체 기간에서만 셉니다.
- 그 기간 예산이 0원인 소분류·항목은 나오지 않습니다.
- 이름이 「사업비」「운영비」인 카테고리만 보여 줍니다.

#### 4.2.9 캘린더
<!-- src: renderBudget#calendar -->

**언제 쓰나** — 어느 날 몇 건, 얼마를 집행했는지 달력으로 훑어볼 때. 보기 전용 화면입니다.

**순서**
1. 「◀」「▶」로 달을 옮깁니다. 처음에는 이번 달이 열립니다.
2. 날짜 칸을 누르면 아래에 「📋 … 집행내역 (…건)」 목록이 열립니다. 같은 날짜를 다시 누르면 닫힙니다.

**화면 요소**

| 요소 | 하는 일 |
|---|---|
| 「📅 집행 캘린더」 | 집행일 기준 월 달력. 일요일은 빨강, 토요일은 파랑 |
| 날짜 칸 | 집행이 있으면 「…건」과 그날 합계 금액 |
| 날짜 목록 | 건마다 항목명·설명·상태·금액·결제 방법·카테고리 > 소분류·수취인 |

**주의**
- 대기 상태 건도 함께 셉니다. 카테고리·상태 필터는 없습니다.
- 목록에서는 고치거나 증빙을 붙일 수 없습니다. [4.2.7](#427-집행내역)에서 하세요.
- 집행이 없는 날을 누르면 「이 날짜의 집행 내역이 없습니다.」가 나옵니다. 달을 옮기면 고른 날짜는 풀립니다.

#### 4.2.10 사업변경신청서
<!-- src: renderBudget, setChangeApplicationModal -->

**언제 쓰나** — 재단 사무국과 이메일로 변경을 협의했고, 재단이 변경신청서 제출을 요청했을 때.

**순서**
1. 먼저 재단 사무국 담당자에게 변경 내용과 사유를 이메일로 문의합니다. 재단이 변경신청서를 요청하면 다음으로 넘어갑니다(수행가이드 p.9).
2. 이 사이트의 팝업을 허용해 둡니다. 「💰 예산관리」 화면에서 탭 위의 「📝 사업변경신청서」를 누르면 「📝 사업변경신청서 생성」 창이 열립니다.
3. 「1. 사업변경취지 및 사유」를 씁니다.
4. 「2. 사업변경내역」 표에 「변경 전」「변경 후」의 「단위사업」「일정」「추진내용」을 씁니다. 줄은 「+ 행 추가」로 늘리고 줄 끝 「✕」로 지웁니다.
5. 「3. 예산변경내역」에서 소분류마다 「변경후 (원)」을 고칩니다. 「변경전 (원)」에는 현재 편성액이 들어 있고, 「증감」「… 소계」「합 계」는 자동으로 계산됩니다. 바뀐 줄은 노란색입니다.
6. 「4. 구체내역」에 「단위사업명」「변경전 금액」「변경후 금액」「산출근거」「사유」를 씁니다. 더 쓰려면 「+ 항목 추가」.
7. 「신청일」을 확인하고 「📝 문서 생성」을 누릅니다. 새 창에 신청서가 열리면 「🖨️ 인쇄 / PDF 저장」으로 PDF를 만들고, 직인을 확인해 재단에 이메일로 냅니다.

**화면 요소**

| 요소 | 하는 일 |
|---|---|
| 「1. 사업변경취지 및 사유」 | 변경 취지와 사유. 문서 1절에 그대로 들어갑니다 |
| 「2. 사업변경내역」 | 변경 전·후의 단위사업·일정·추진내용 표 |
| 「3. 예산변경내역」 | 「관리그룹」「단위사업」「변경전 (원)」「변경후 (원)」「증감」 |
| 「4. 구체내역」 | 변경하는 단위사업별 금액·산출근거·사유 카드. 오른쪽 위 「✕」로 지웁니다 |
| 「취소」 / 「📝 문서 생성」 | 창 닫기 / 새 창에 신청서 열기 |
| 새 창의 「🖨️ 인쇄 / PDF 저장」「✕ 닫기」 | 브라우저 인쇄 창 열기(종이·PDF) / 새 창 닫기 |

**만들어지는 문서**
- 새 브라우저 창에 A4 문서(HTML)가 열립니다. 1~4절, 신청일, 「기관명」과 「단체직인 이미지」가 들어갑니다 → [4.9.3](#493-기관-정보). 직인이 없으면 「(단체직인 또는 대표자서명)」 자리가 남습니다.
- 한글(HWPX) 파일은 만들지 않습니다. PDF는 인쇄 창의 "PDF로 저장"으로 만듭니다.
- 입력 내용은 앱에 저장되지 않습니다. 만든 PDF를 보관하세요.

**주의**
- 팝업이 막히면 「팝업이 차단되었습니다. 팝업 허용 후 다시 시도하세요.」가 뜨고 입력 창도 닫힙니다. 창 바깥을 누르거나 「취소」를 눌러도 닫힙니다. 다시 열면 입력이 처음으로 돌아갑니다.
- 문서의 「3. 예산변경내역」 표는 앱에 처음부터 들어 있는 2026 편성 구조로 만들어집니다. 활성 프로젝트의 소분류 구성이 이와 다르면 입력한 금액이 문서에 빠질 수 있으니 출력물을 꼭 확인하세요.
- 「4. 구체내역」은 「단위사업명」을 쓴 카드만 문서에 들어갑니다.
- 사업변경 신청은 사업종료일 2개월 전인 2026-10-31까지입니다. 메뉴 대시보드에 「사업변경신청 마감」 알림이 30일 전부터 뜹니다. 재단 심사에 1주일쯤 걸릴 수 있습니다(수행가이드 p.9).
- 예비비를 같은 단위사업의 다른 항목으로 50만원 이상 옮기거나 다른 단위사업으로 옮길 때도 사업변경신청이 필요합니다(수행가이드 p.13).
- 승인된 변경을 앱의 편성에 반영하는 방법과 한계는 → [4.2.2](#422-예산편성표).

### 4.3 일정관리
<!-- src: renderSchedule, renderScheduleModal -->

**언제 쓰나** — 교육·캠페인·회의 같은 사업 일정을 달력에 남기고, 필요하면 Google 캘린더와 주고받을 때.

**순서 — 일정 등록**
1. 「+ 일정 추가」를 누르거나 달력에서 날짜를 두 번 누릅니다. 두 번 누른 날짜가 「시작일 *」에 들어갑니다.
2. 「새 일정 등록」 창에서 「제목 *」「카테고리 *」「시작일 *」을 채웁니다. 「세부 카테고리」「종료일」「시작 시간」「종료 시간」「장소」「최대 참여자 수」「상태」「설명」은 필요한 만큼 씁니다.
3. 「등록」을 누릅니다. Google이 연결되어 있으면 Google 캘린더에도 함께 들어갑니다.
4. 달력이나 목록에서 일정을 누르면 상세 창이 열립니다. 「수정」「삭제」「닫기」가 있습니다.

**순서 — Google 캘린더 (선택)**
1. 「Google Calendar 연결」을 누르고 Google 창에서 계정을 고른 뒤 캘린더 권한을 허용합니다. 이 앱은 내 Google 기본 캘린더를 읽고 씁니다.
2. 연결되면 보고 있는 달과 앞뒤 한 달씩, 석 달의 Google 일정이 함께 나옵니다(달력에서는 파란 칸, 목록에서는 「G」 표시). 앱 일정과 제목·날짜가 같은 Google 일정은 한 번만 보입니다.
3. 아래 표에서 방향을 확인하고 버튼을 누릅니다. 다 쓰면 「연결 해제」를 누릅니다.

| 버튼 | 방향 | 하는 일 |
|---|---|---|
| 「전체 동기화」 | 앱 → Google | 앱의 모든 일정을 보냅니다. 불러온 Google 일정 중 제목·날짜가 같은 것은 건너뜁니다 |
| 「G Google에 동기화」 (앱 일정 상세, 연결 중일 때) | 앱 → Google | 이 일정 1건을 보냅니다. 중복 검사가 없습니다 |
| 「등록」 (연결 중일 때) | 앱 → Google | 새로 등록한 일정이 자동으로 함께 들어갑니다 |
| 「Supabase에 가져오기」 (Google 일정 상세) | Google → 앱 | 그 일정을 앱에 저장합니다(카테고리 「기타」, 상태 「예정」). 같은 제목·시작일 일정이 있으면 막습니다. Supabase는 이 앱의 서버 저장소입니다 |

**화면 요소**

| 요소 | 하는 일 |
|---|---|
| 「◀」「오늘」「▶」 | 이전 달 · 이번 달 · 다음 달 |
| 「월간」/「목록」 | 달력 / 그 달 일정 목록. 하루에 3개가 넘으면 「+…개 더보기」를 눌러 목록으로 봅니다 |
| 날짜 한 번 누르기 | 달력 아래에 「📅 … 일정 (…건)」 요약이 나옵니다 |
| 「카테고리 *」 | 「교육」「캠페인」「회의」「평가」「기타」(처음 값 「교육」). 달력 색과 아래 범례가 이 구분을 따릅니다 |
| 「상태」 | 「예정」「진행중」「완료」「취소」 |
| 「📋 출석 관리」 (상세 창) | 사람마다 「출석」「결석」「지각」을 고르고 「🖨️ 출석부 인쇄」로 새 창에서 인쇄하는 기능입니다. 지금은 나타나지 않습니다(아래 주의) |

**주의**
- 참여자 명단을 넣을 칸도, 서버에 저장할 곳도 없습니다. 그래서 「📋 출석 관리」와 「🖨️ 출석부 인쇄」는 지금 나타나지 않습니다 → [13장](#13-현재-한계).
- 앱에서 일정을 고치거나 지워도 Google 쪽은 그대로입니다. Google 캘린더에서 따로 고치세요.
- 「전체 동기화」는 화면에 불러온 석 달치 Google 일정과만 비교합니다. 그 밖의 일정은 누를 때마다 Google에 또 들어가니 한 번만 누르세요.
- Google 연결은 새로고침하면 풀립니다. 연결한 채 오래 두면 동기화가 실패할 수 있으니 「연결 해제」 후 다시 연결하세요. 연결 창이 안 뜨면 팝업 차단을 확인하세요 → [12장](#12-문제-해결).
- Google의 종일 일정을 가져오면 「종료일」이 하루 늦게 들어갑니다. 가져온 뒤 「수정」에서 고치세요.
- 일정은 로그인한 사람 누구나 고치고 지울 수 있고, 활동 로그에 남지 않습니다.

### 4.4 갤러리
<!-- src: renderGallery -->

**언제 쓰나** — 활동 사진과 결과물을 분류해 모아 두고, 결과보고와 뉴스레터에 쓸 때.

**순서**
1. 「✏️ 글쓰기」를 누릅니다.
2. 「📸 사진 등록」에서 「카테고리」를 고르고 「제목」을 씁니다. 「설명」「촬영일」「촬영 장소」「촬영자」는 선택입니다.
3. 「📎 첨부파일 (…/…)」 칸을 누르거나 파일을 끌어다 놓습니다. 한 번에 5개, 파일당 10MB까지입니다.
4. 「🔒 비밀번호」를 정하고 「등록」을 누릅니다. 제목과 비밀번호가 있어야 눌립니다. 첫 번째 사진이 목록의 대표 사진이 됩니다.
5. 목록에서 카드를 누르면 상세 화면이 열립니다. 사진을 누르면 크게 보이고, 여러 장이면 「◀」「▶」로 넘깁니다.

> 예시 — 캠페인 사진 4장을 「캠페인」 분류로 올리면서 「촬영일」·「촬영 장소」를 채우면, 결과보고 증빙에 쓰는 사진·일시·장소가 한 글에 모입니다.

**화면 요소**

| 요소 | 하는 일 |
|---|---|
| 분류 탭 | 「전체」「현장사진」「결과물」「교육자료」「캠페인」「행사」「영수증」「기타」. 새 글의 처음 값은 「현장사진」 |
| 「검색어를 입력하세요」 | 제목·설명·촬영 장소·촬영자에서 찾습니다 |
| 「📦 전체 다운로드」 | 지금 고른 분류·검색 결과 전체(모든 쪽)의 첨부파일을 `갤러리_날짜.zip`으로 받습니다. 글 제목마다 폴더가 생기고, 사진이 아닌 첨부(PDF 등)도 함께 들어갑니다. 같은 폴더에 이름이 같은 파일은 "사진 (2).jpg"처럼 번호가 붙고, 받지 못한 파일이 있으면 몇 장이 빠졌는지 알려 줍니다. 받는 동안 「⏳ 압축 중...」 |
| 카드 | 대표 사진, 분류, 제목, 촬영일(없으면 등록일), 장소(없으면 「미지정」), 조회수. 한 쪽에 10개 |
| 상세 화면 | 사진 넘기기·크게 보기, 사진이 아닌 첨부의 「⬇ 다운로드」, 「💬 댓글 (…)」, 「← 목록으로」「✏️ 수정」「🗑️ 삭제」 |
| 「📝 사진 수정」 | 「📎 기존 첨부파일 (…)」에서 파일을 하나씩 지우고(확인하면 바로 삭제) 새 파일을 더합니다 |

**주의**
- 관리자가 아니면 「✏️ 수정」「🗑️ 삭제」 때 글을 쓸 때 정한 비밀번호를 묻습니다. 삭제하면 첨부 사진까지 지워지고 되돌릴 수 없습니다.
- 올릴 수 있는 파일은 사진(JPG·PNG·GIF·WEBP·SVG), PDF, 한글(HWP), 워드·엑셀·파워포인트, TXT·CSV, ZIP입니다. 아이폰 HEIC 사진, 동영상, HWPX는 「허용되지 않는 파일 형식입니다.」로 거부됩니다. 한글 파일도 브라우저가 형식을 알아보지 못하면 거부되니 JPG·PDF로 바꿔 올리세요.
- 「영수증」 분류는 보관용입니다. 집행 증빙은 집행 건에 「📎 첨부하기」로 붙여야 인정됩니다 → [4.2.7](#427-집행내역).
- 얼굴이 나온 사진은 초상 사용 동의를 확인하고 올리세요. 뉴스레터 1단계 「📸 갤러리 (…)」에서 골라 밖으로 나갈 수 있습니다 → [4.7](#47-뉴스레터).
- 글이 많으면 압축에 시간이 걸립니다. 분류를 골라 나눠 받으면 빠릅니다.

### 4.5 게시판
<!-- src: renderBoard, BoardWriteForm -->

**언제 쓰나** — 공지·자료·보고서를 글과 첨부파일로 남기고 댓글로 의견을 주고받을 때.

**순서**
1. 「✏️ 글쓰기」를 누릅니다.
2. 「분류」를 고릅니다(처음 값은 「공지」). 「제목」과 「내용」을 씁니다.
3. 내용에 인터넷 주소를 쓰면 잠시 뒤 「🔗 링크 미리보기」 카드가 생깁니다. 필요 없는 카드는 ×로 뺍니다.
4. 파일은 「📎 첨부파일 (…/…)」 칸을 누르거나 끌어다 놓습니다. 한 번에 5개, 파일당 10MB까지입니다.
5. 「🔒 비밀번호」를 정합니다. 관리자는 「📌 상단 고정」을 켤 수 있습니다.
6. 「등록」을 누릅니다. 제목·내용·비밀번호 중 하나라도 비어 있으면 눌리지 않습니다.

**주의**
- 관리자가 아니면 수정·삭제할 때 글 비밀번호가 필요합니다. 틀리면 「비밀번호가 일치하지 않습니다.」가 뜹니다. 잊었으면 관리자 계정으로 고치세요.
- 글 비밀번호는 로그인 비밀번호와 별개이며, 글을 쓸 때만 정하고 나중에 바꿀 수 없습니다.
- 수정 화면에서는 파일을 더할 수만 있고 기존 첨부는 지울 수 없습니다. 글을 지우면 첨부도 함께 지워지고 되돌릴 수 없습니다.
- 운영 사이트에서는 보안 설정 때문에 링크 미리보기에 제목·그림 대신 주소만 나올 수 있습니다. 링크는 정상으로 열립니다.
- 받는 파일 형식과 거부되는 형식은 갤러리와 같습니다 → [4.4](#44-갤러리).

### 4.6 회계가이드
<!-- src: renderGuide -->

**언제 쓰나** — 돈을 쓰기 전에 계정항목·결제 방법·증빙을 확인하거나, 강사비·원고료 같은 기타소득의 원천징수액을 계산할 때. 규정 원문은 이 화면과 수행가이드에 있고, 이 절은 어느 탭에서 무엇을 찾는지만 안내합니다.

**순서** — 원천징수 계산
1. 「💰 원천징수 계산기」 탭의 「지급 금액 (원)」에 세금을 떼기 전 금액을 넣습니다.
2. 「필요경비율」을 고릅니다. 처음에는 「60% (인적용역: 강연료, 원고료 등)」이 선택돼 있습니다. 상금은 「80% (불특정 다수 경쟁 대회 상금)」, 기프티콘 등은 「0% (필요경비 없음: 기프티콘 등)」입니다.
3. 바로 아래에 「기타소득금액」「소득세 (20%)」「지방소득세 (소득세의 10%)」「원천징수 합계」「실수령액」이 나옵니다. 기타소득금액이 5만 원 이하이면 「과세최저한 적용: 기타소득금액 5만원 이하 → 원천징수 없음」이 뜹니다.

> 예시 — 강사비 300,000원, 60%: 기타소득금액 120,000원 → 소득세 24,000원 + 지방소득세 2,400원 = 26,400원(8.8%), 실수령액 273,600원.

**화면 요소** — 탭 5개

| 탭 | 답하는 질문 | 이럴 때 엽니다 |
|---|---|---|
| 「📋 기본원칙」 | 어떤 통장·카드로 쓰나, 지출은 어떤 순서로 처리하나(「지출처리 흐름」), 무엇이 금지인가(「주의 및 금지 사항」), 사업변경은 언제·어떻게 하나(「사업변경 안내」) | 첫 집행 전, 사업변경을 검토할 때 |
| 「📂 계정항목별 안내」 | 이 비용은 어느 계정항목인가. 항목 카드를 누르면 「제한사항」「결제 방법」「필요 증빙서류」와 💡 주의가 펼쳐집니다. 「원천징수 대상」 표시가 붙은 항목은 지급할 때 원천징수를 확인합니다 | 결제하기 전, 집행등록에서 예산 항목을 고르기 전 |
| 「🧾 적격증빙 가이드」 | 어떤 영수증이 인정되나(「적격증빙 영수증 우선순위」), 영수증은 어떻게 붙이고 편철하나(「영수증 관리 원칙」), 상품권·수상금은 어떻게 증빙하나 | 영수증을 받을 때, 정산 서류를 묶을 때 |
| 「💰 원천징수 계산기」 | 얼마를 떼고 얼마를 보내나, 신고·납부는 언제까지인가(「원천징수 처리 절차」), 소득 종류별 세율은 얼마인가(「소득구분 및 세율 요약」) | 강사비·자문비·상금을 주기 전, 매월 신고 전 |
| 「❓ FAQ」 | 세액을 어느 통장에서 내나, 미등록단체의 의무, 면제, 반기납부, 이자, 지출 오류, 잔액 반납, 개인정보 문서, 오픈뱅킹 | 위 탭에서 답을 못 찾을 때 |

**주의**
- 계산 결과는 저장되지 않습니다. 실제 지급은 [4.2.3](#423-집행등록)에서 등록합니다.
- 예산관리 「🧮 원천징수계산」([4.2.6](#426-원천징수계산))은 소득 유형과 상관없이 "125,000원 초과 시 8% + 지방소득세(소득세의 10%)"로 계산합니다. 이 화면의 60%와 같은 기준입니다. 상금(80%)·필요경비 없는 소득은 이 화면으로 계산하고, 사업소득·일용근로소득은 「소득구분 및 세율 요약」의 세율을 참고해 세무 확인을 받으세요.
- 수행가이드는 같은 사람에게 하루에 준 강사비·회의참석비의 합계로 원천징수 여부를 판단합니다. 같은 날 여러 건이면 합계를 넣으세요.
- 「필요 증빙서류」는 집행등록 「📄 필요 증빙서류」와 같은 규칙에서 나옵니다. 규칙이 없는 임차료·예비비는 「해당 항목의 증빙서류에 준함」으로 나옵니다.
- 신고·납부 기한, 사업변경 마감, 잔액 반납 기한은 [11장](#11-업무-달력--언제-무엇을)에 모았습니다.

### 4.7 뉴스레터
<!-- src: renderNewsletter -->

**언제 쓰나** — 등록해 둔 일정·게시글·갤러리 사진을 골라 소식지를 만들고, SNS·이메일로 보내거나 인쇄할 때. 화면 제목은 「📰 뉴스레터 제작」이고 「내용 선택」→「템플릿 선택」→「배치 / 편집」 3단계로 진행합니다.

**순서**
1. **내용 선택** — 「뉴스레터 정보」에 「제목」「발행 호수」「발행일」(처음에는 오늘)을 넣습니다. 「기간 필터」에 시작일과 종료일을 넣으면 그 사이에 시작하는 일정과 그 사이에 쓴 게시글만 목록에 남습니다. 갤러리는 기간으로 거르지 않습니다.
2. 「📅 일정 (…)」「📋 게시글 (…)」「📸 갤러리 (…)」에서 넣을 것을 체크합니다. 일정·게시글 목록 위의 분류 상자로 더 좁힐 수 있습니다. 「다음: 템플릿 선택 →」을 누릅니다.
3. **템플릿 선택** — 카드 7개 중 하나를 누릅니다(처음에는 「커뮤니티 / 카드 리스트」). 고른 양에 따라 💡 추천 문구가 뜹니다. 색·글꼴은 「🎨 디자인 커스터마이징」의 「주 색상」「보조 색상」「폰트」(「템플릿 기본 (고딕)」「명조」「시스템 고딕」)로 바꾸고 「기본값 복원」으로 되돌립니다. 「다음: 배치 및 편집 →」을 누릅니다.
4. **배치 / 편집** — 「인사말」「마무리말」을 쓰고 「콘텐츠 배치」에서 섹션·항목의 순서와 제목을 다듬습니다. 오른쪽 「미리보기 — …」가 바로 바뀝니다.
5. 「💾 임시저장」을 누릅니다(2·3단계에 있음). 「임시저장되었습니다.」가 뜨면 서버에 저장된 것입니다.
6. 「📋 SNS 복사」「⬇️ HTML 다운로드」「🖨️ 인쇄 / 새 창」 중 하나로 내보냅니다. 저장해 둔 뉴스레터면 「이 뉴스레터를 발행 완료로 표시할까요?」가 뜹니다. 실제로 보냈다면 확인을 누릅니다.

> 예시 — 9월호: 「기간 필터」 2026-09-01 ~ 2026-09-30 → 게시글 2건·일정 3건·갤러리 1건 체크 → 「커뮤니티 / 카드 리스트」 → 「주요 소식」을 "이달의 소식"으로 고치고 「주요 일정」을 「↑」로 맨 위에 → 「💾 임시저장」 → 「⬇️ HTML 다운로드」.

**주의**
- 「💾 임시저장」은 화면 전체(선택·필터·템플릿·색·섹션 순서와 제목·고친 글·링크)를 저장합니다. 저장하지 않으면 새로고침하거나 프로젝트를 바꿀 때 사라집니다. 처음 저장하면 「임시저장」 상태입니다.
- 발행 완료 표시는 상태만 「발행됨」으로 바꾸고 내용은 저장하지 않습니다. 고쳤으면 먼저 「💾 임시저장」하고 내보내세요. 저장한 적 없는 뉴스레터는 묻지 않고, 「발행됨」을 고쳐 저장해도 「발행됨」으로 남습니다.
- 「불러오기」 뒤 「💾 임시저장」하면 불러온 뉴스레터를 덮어씁니다. 지난 호를 남기려면 「복제」부터 하세요. 빈 뉴스레터로 새로 시작하는 단추는 없으니 브라우저를 새로고침하세요.
- 「기간 필터」는 목록만 줄입니다. 이미 체크한 항목은 목록에서 사라져도 그대로 들어갑니다(제목 옆 개수로 확인).
- 섹션 순서·제목은 단계를 오가도 유지됩니다. 1단계에서 뺀 항목은 빠지고, 새로 고른 항목은 그 섹션 끝에 붙습니다.
- 사진은 게시글에 첨부한 이미지와 갤러리 글의 첫 사진을 씁니다.
- 카카오톡처럼 글자만 받는 곳에는 서식 없는 글자만 붙고, 빈 줄이나 `&amp;` 같은 기호가 섞일 수 있습니다. 「복사에 실패했습니다.」가 뜨면 「⬇️ HTML 다운로드」를 쓰세요.
- 「팝업이 차단되었습니다.」가 뜨면 브라우저 주소창에서 "팝업 허용"을 누르고 다시 합니다.
- AI로 본문을 다듬는 단추는 지금 없습니다. 「본문」 옆에 「(AI 재작성 결과에 이어서 수정 가능)」 문구가 남아 있지만 직접 고쳐 쓰는 칸입니다([13장](#13-현재-한계)).
- 일정·게시글 제목에 학교 실명이 있으면 뉴스레터에도 그대로 나갑니다. 밖으로 보낼 때는 「✏️」로 "OO 소재 반도체고"처럼 고치세요. 머리말·꼬리말의 단체명은 활성 프로젝트의 「단체명 *」에서 옵니다.

### 4.8 학교관리
<!-- src: renderSchools -->

**언제 쓰나** — 협력 학교의 기본정보·담당교사·학생 수를 기록하고, 학교에 간 교과서와 NEIS 시간표를 확인할 때.

**순서** — 학교 등록 (관리자)
1. 「🏫 학교 관리」에서 「+ 학교 등록」을 누릅니다(학교가 하나도 없으면 「첫 학교 등록하기」).
2. 「🔍 NEIS 학교 검색」 칸에 학교 이름을 두 글자 이상 넣고 「🔍 NEIS 검색」(또는 Enter)을 누릅니다. 결과(최대 10개)에서 학교를 누르면 「📋 기본정보」 칸이 채워집니다.
3. 「👨‍🏫 담당교사 · 학교정보」에 「교장」「담당교사」「담당교사 전화」「담당교사 이메일」「전공 (콤마로 구분)」과 「1학년」「2학년」「3학년」 학생 수를 넣습니다. 「합계: …명」은 자동으로 계산됩니다.
4. 「📎 기타」에서 「공지사항 URL」「협력 시작일」「메모」를 넣고 「상태:」를 「활동」/「비활동」 중에 고른 뒤 「💾 저장」을 누릅니다.

> 예시 — 학교명 일부로 찾아 "OO반도체고등학교"를 고르면 「학교명 *」「주소」「전화」「교육청」 등이 채워지고 「약칭」에는 "OO반도체고"가 들어갑니다. 학년별로 120·110·100을 넣으면 합계가 330명이 됩니다.

**화면 요소**

| 요소 | 하는 일 |
|---|---|
| 학교 카드 | 약칭, 상태 점(초록 활동·회색 비활동), 주소·담당교사·전화, 「🎓 …명」「📖 교과서 …종」. 누르면 상세가 열립니다 |
| 「🔍 NEIS 검색」 | 고른 학교로 「학교명 *」「주소」「전화」「FAX」「홈페이지」「교육청」「설립구분」, 남녀공학 구분(상세에서 설립구분 옆), 개교일과 시간표용 학교 코드(화면에 안 보임)를 채웁니다. 「약칭」은 비어 있을 때만 채웁니다. 「교육청」「설립구분」은 직접 고칠 수 없습니다 |
| 「✏️ 수정」「🗑️ 삭제」 | 상세 맨 위(관리자만). 삭제는 「정말 삭제하시겠습니까? 관련 교과서 정보도 함께 삭제됩니다.」 확인 뒤 교과서 기록까지 지웁니다 |
| 「📚 교과서 목록 (…종)」의 「+ 교과서」 | (관리자만) 「교과서명 *」「과목」「출판사」, 상태 「예정」「배포」「사용중」, 「안전교과서」「센터 개발」을 정하고 「추가」. 표에 「⚠️ 안전」「센터」로 표시되고 🗑️로 지웁니다 |
| 「📅 시간표」의 「🔍 시간표 조회」 | 「주간:」(아무 날짜나 고르면 그 주 월~금, 「◀ 이전」「다음 ▶」로 한 주씩), 「학년:」(「전체」·1~3학년), 「반:」(「전체」·1~5반)을 정하고 누릅니다. 교시×요일 표가 나오고, 자료가 없는 날은 🚫, 안전 관련 과목은 칸이 강조되고 「⚠️ 안전 관련 과목: …」에 모입니다 |
| 「📅 관련 활동 (…건)」 | 제목이나 장소에 이 학교의 약칭이나 학교명이 들어간 일정을 10건까지 보여 줍니다 |
| 「📢 공지사항」 | 「공지사항 URL」을 넣은 학교만 보입니다. 「새 탭 열기 ↗」로 학교 공지 페이지를 엽니다 |

**주의**
- 학교 등록·수정·삭제와 교과서 추가·삭제는 관리자만 됩니다. 다른 역할은 목록·상세 보기와 시간표 조회만 됩니다.
- 「📅 시간표」는 NEIS 검색으로 고른 학교에만 나옵니다. 직접 입력한 학교는 「✏️ 수정」에서 NEIS로 다시 골라 저장하세요. 이때 학교명·주소·전화 등은 NEIS 값으로 바뀝니다.
- 시간표는 고등학교 시간표만 불러옵니다. 주·학년·반을 바꾼 뒤에는 「🔍 시간표 조회」를 다시 누르세요. 학년·반이 「전체」면 같은 교시의 여러 반 과목이 쉼표로 함께 나옵니다.
- 「해당 기간의 시간표 데이터가 없습니다.」는 방학·휴업일이거나 그 학년·반 자료가 없을 때 뜹니다. 다른 주나 「전체」로 다시 조회하세요.
- NEIS 검색 결과가 없으면 안내 없이 목록이 비어 있습니다. 정식 학교명의 일부로 다시 찾거나 직접 입력하세요.
- 교과서는 고칠 수 없습니다. 틀리면 지우고 다시 추가합니다.
- 메뉴는 활성 프로젝트에 학교관리 모듈이 있을 때만 보입니다([4.9.4](#494-프로젝트-관리)). 학교 목록은 모든 프로젝트가 함께 씁니다.
- 학교 실명과 담당교사 연락처는 앱 안에서만 씁니다. 홍보물·보고서·뉴스레터에는 "OO 소재 반도체고"처럼 지역+유형으로 씁니다([10장](#10-개인정보재단-규정-안전장치)).

#### 4.9.1 사용자 관리
<!-- src: renderAdmin#users -->

**언제 쓰나** — 로그인할 사람의 계정을 만들거나, 역할을 바꾸거나, 잊어버린 비밀번호를 새로 정해 줄 때.

**순서**
1. 「+ 새 사용자 추가」를 누릅니다.
2. 「아이디 *」「이름 *」「비밀번호 *」를 입력하고 「역할」을 고릅니다. 역할의 처음 값은 「직원」입니다.
3. 「사용자 추가」를 누르면 「'…' 사용자가 추가되었습니다.」가 뜨고, 목록에 「● 활성」으로 나옵니다.
4. 아이디와 첫 비밀번호를 본인에게 직접 전합니다. 앱은 첫 로그인 때 비밀번호를 바꾸라고 요구하지 않으니, 머리글의 이름을 눌러 「🔒 비밀번호 변경」에서 바꾸도록 안내하세요([2장](#2-처음-준비)).

**화면 요소**

| 요소 | 하는 일 |
|---|---|
| 「아이디 *」 | 로그인 아이디. 대소문자·띄어쓰기까지 똑같이 입력해야 로그인됩니다. 만든 뒤에는 바꿀 수 없습니다 |
| 「비밀번호 *」 | 첫 비밀번호. 길이·조합 규칙이 없으니 추측하기 어렵게 정하세요. 되돌릴 수 없는 값(해시)으로만 저장되어 관리자도 원래 비밀번호를 볼 수 없습니다 |
| 「역할」 | 「관리자」「직원」「참여자」「열람자」 중 하나. 실제 권한은 아래 주의를 보세요 |
| 「이메일」 | 다른 계정과 겹칠 수 없습니다(「이미 존재하는 아이디 또는 이메일입니다.」). 비워 두면 아이디 뒤에 센터 도메인을 붙인 주소가 자동으로 들어갑니다 |
| 「전화번호」「소속」「직위」 | 기록용입니다. 「소속」의 처음 값은 청년노동자인권센터입니다 |
| 「수정」 | 이름·역할·연락처를 고칩니다. 「새 비밀번호 (변경시에만)」에 입력하면 지금 비밀번호를 몰라도 새로 정해지고, 비워 두면 그대로입니다 |
| 「삭제」 | 계정을 「● 비활성」으로 바꿔 로그인만 막습니다. 계정 정보와 기록은 남습니다. 지금 로그인한 자기 계정은 지울 수 없습니다 |
| 「복원」 | 비활성 계정을 다시 「● 활성」으로 바꿉니다. 확인창 없이 바로 바뀝니다 |

**주의**
- **역할은 사실상 「관리자」와 그 밖의 둘로만 나뉩니다.** 「직원」「참여자」「열람자」는 할 수 있는 일이 같습니다. 「열람자」도 집행 등록·수정, 집행내역 일괄 승인·삭제, 거래처 규칙 변경, 일정 추가·삭제를 할 수 있습니다. 아름다운재단 담당자처럼 보기만 할 사람에게는 계정 대신 대시보드 「🖨️ 인쇄」나 「📸 HTML 스냅샷」 출력물을 보내는 방법도 있습니다([9장](#9-레퍼런스), [13장](#13-현재-한계)).
- 자기 계정의 역할을 「관리자」가 아닌 것으로 바꾸면 저장 즉시 「⚙️ 관리자」 메뉴가 사라집니다. 다른 관리자 계정이 없으면 앱 안에서는 되돌릴 수 없습니다.
- 삭제·역할 변경·비밀번호 변경은 그 사람이 이미 로그인해 둔 브라우저에는 바로 적용되지 않습니다. 그 로그인이 끝나야(로그인 후 최대 24시간, 또는 로그아웃) 반영됩니다.
- 로그인 화면에는 비밀번호 찾기가 없습니다. 잊었다면 관리자가 「수정」에서 새 비밀번호를 정해 줍니다.

#### 4.9.2 수급자 관리
<!-- src: renderAdmin#recipients -->

**언제 쓰나** — 운영인건비를 받는 사람의 생년월일·주소를 급여지급명세서에 자동으로 채우고 싶을 때.

**순서**
1. 「+ 수급자 등록」을 누릅니다.
2. 「성명 *」에 집행의 「수취인」과 똑같은 이름을 적고 「생년월일」「주소」를 입력합니다.
3. 「수급자 등록」을 누르면 「'…' 수급자가 등록되었습니다.」가 뜨고 목록에 추가됩니다.
4. 이제 「📝 집행등록」의 「수취인」 칸에서 이 이름을 목록으로 고를 수 있고, 이 사람의 운영인건비 집행으로 만드는 급여지급명세서에 생년월일·주소가 채워집니다([4.2.7](#427-집행내역)).

**화면 요소**

| 요소 | 하는 일 |
|---|---|
| 「성명 *」 | 집행의 「수취인」과 띄어쓰기까지 같아야 연결됩니다 |
| 「생년월일」 | 명세서의 생년월일 칸에 적은 그대로 찍힙니다. 형식은 자유입니다 |
| 「주소」 | 명세서의 주소 칸에 찍힙니다 |
| 「전화번호」「비고」 | 관리용 메모입니다. 서식에는 쓰이지 않습니다 |
| 「수정」 | 칸을 고친 뒤 「수정 저장」을 누릅니다 |
| 「삭제」 | 확인창 뒤 목록에서 숨깁니다. 서버에는 정보가 남으니 개인정보를 지우려면 먼저 「수정」에서 칸을 비워 저장하세요. 되살리는 버튼이 없으니 다시 쓰려면 새로 등록합니다 |

생년월일·주소가 모두 비어 있으면 급여지급명세서 HWPX 미리보기에 「⚠️ 수령자 프로필(생년월일·주소)이 등록되지 않아 해당 칸이 빈칸으로 출력됩니다.」와 「수급자 관리로 이동」이 뜹니다. 그대로 만들면 두 칸이 빈칸입니다. 화면·PDF 명세서는 안내 없이 빈칸으로 나옵니다.

**주의**
- 개인정보입니다. 급여지급명세서가 필요한 사람만, 필요한 칸만 적고 주민등록번호·계좌번호는 넣지 마세요.
- 같은 이름을 두 번 등록하지 마세요. 이름이 같으면 목록에서 먼저 나오는 사람의 정보가 쓰입니다.
- 이 탭은 관리자만 보지만 급여지급명세서는 누구나 만들 수 있어서, 다른 역할 사용자도 서식에 찍힌 생년월일·주소를 보게 됩니다.

#### 4.9.3 기관 정보
<!-- src: renderAdmin#orgSettings -->

**언제 쓰나** — 급여지급명세서·회의진행일지·사업변경신청서에 들어갈 기관 정보와 직인을 처음 정하거나 바꿀 때.

**순서**
1. 「기관명」「대표자명」「사업자등록번호 (고유번호)」「기관주소」를 입력합니다.
2. 「단체직인 이미지」에서 직인 그림 파일을 고르면 미리보기가 나옵니다.
3. 「💾 저장」을 누릅니다. 「기관 정보가 저장되었습니다.」가 뜨면 끝입니다.

**화면 요소** — 칸마다 쓰이는 곳

| 요소 | 쓰이는 곳 |
|---|---|
| 「기관명」 | 급여지급명세서·회의진행일지·사업변경신청서에 찍히는 단체명(급여지급명세서·회의진행일지는 HWPX에도). 비우면 '청년노동자인권센터'가 들어갑니다 |
| 「대표자명」 | 급여지급명세서의 지급자 칸 |
| 「사업자등록번호 (고유번호)」 | 급여지급명세서의 지급자 칸. 비우면 화면·PDF 명세서에는 고유번호가 없으면 생략한다는 안내 글자가 찍힙니다 |
| 「기관주소」 | 급여지급명세서의 지급자 칸 |
| 「기관 전화번호」 | 저장만 되고, 지금은 어느 서식에도 쓰이지 않습니다 |
| 「단체직인 이미지」 | 화면(새 창)·PDF로 만드는 급여지급명세서·회의진행일지·사업변경신청서의 서명 자리. 없으면 그 자리에 서명 안내 글자가 찍힙니다. HWPX 파일에는 들어가지 않습니다 |
| 「🗑 직인 삭제」 | 올린 직인을 지웁니다. 「💾 저장」을 눌러야 서버에서도 지워집니다 |

「기관명」이 비었거나, 급여지급명세서인데 「대표자명」이 비었으면 HWPX 서식 미리보기에 「⚠️ 기관정보가 비어 있어 해당 칸이 빈칸으로 출력됩니다.」와 「기관정보 설정으로 이동」이 뜹니다. 그대로 「📥 생성 및 다운로드」를 누르면 빈칸인 채로 만들어집니다.

**주의**
- 고친 값은 저장 전에도 지금 창에서 만드는 서식에 바로 쓰이지만, 「💾 저장」을 누르지 않으면 새로고침할 때 사라집니다.
- 직인은 배경이 투명한 PNG가 가장 자연스럽습니다. 그림 파일이 데이터베이스에 그대로 저장되고 앱을 열 때마다 불러오므로 용량이 작은 파일을 쓰세요.
- 화면 맨 위 머리글과 뉴스레터에 나오는 단체명은 이 값이 아니라 활성 프로젝트의 「단체명 *」입니다([4.9.4](#494-프로젝트-관리)).
- 화면·PDF 급여지급명세서 표의 기관명 칸은 이 값과 상관없이 '청년노동자인권센터'로 고정되어 있습니다. 아래 서명줄의 단체명만 「기관명」을 따릅니다.

#### 4.9.4 프로젝트 관리
<!-- src: renderAdmin#projects -->

**언제 쓰나** — 연차나 사업이 바뀌어 예산 구조(카테고리 → 소분류 → 항목)와 보이는 메뉴를 새로 정할 때.

프로젝트는 예산 구조와 메뉴 구성(모듈)의 묶음입니다. 한 번에 하나만 활성이고, 활성 프로젝트의 이름·「단체명 *」·총 예산이 화면 맨 위 머리글에 나옵니다. 프로젝트가 하나도 없으면 앱에 내장된 2026년 예산 구조로 동작합니다.

**순서 — 새 프로젝트**
1. 「💾 현재 구조 저장」(앱에 내장된 2026년 예산 구조) 또는 「📥 엑셀 업로드」(예산 계획 파일 .xlsx·.xls·.csv)를 누릅니다.
2. 엑셀이면 「✅ 파싱 완료: …」에 나온 카테고리·항목 수와 총 예산이 계획서와 같은지 먼저 확인합니다.
3. 「프로젝트 이름 *」「단체명 *」「사업년도」를 확인하고, 「활성 모듈 선택」에서 보일 메뉴를 체크한 뒤 「프로젝트 생성」을 누릅니다.
4. 첫 프로젝트는 바로 활성이 됩니다. 두 번째부터는 목록의 「활성화」를 누르고 「이 프로젝트로 전환하시겠습니까?…」에서 확인합니다.

**순서 — 연차가 바뀔 때**: 지금 프로젝트의 「📋 복제」 → 「새 사업년도:」에 연도 입력(처음 값은 다음 해) → 새 프로젝트의 「활성화」. 전후 점검은 [11장](#11-업무-달력--언제-무엇을)을 보세요.

**엑셀 양식** — 첫 시트에서 처음 10줄 안에 값이 4칸 이상 찬 줄을 제목 줄로 봅니다. 열 이름에 "대분류"(카테고리), "소분류", "항목", "유형"(계정 이름), "총예산"이나 "예산액", "상반기"·"하반기", "산출근거"나 "비고"가 들어 있으면 그 열을 씁니다. 대분류·소분류 빈칸은 윗줄 값을 이어받고, 항목이 빈 줄은 건너뜁니다. "유형"은 사업인건비처럼 회계 계정 이름을 그대로 써야 필요 증빙 안내가 나오고, 비우면 일반지출이 됩니다.

**화면 요소**

| 요소 | 하는 일 |
|---|---|
| 「활성화」 | 이 프로젝트로 전환합니다. 활성 프로젝트에는 버튼 대신 ✅ 표시와 초록 테두리가 붙습니다 |
| 「📋 복제」 | 예산 구조·모듈을 그대로 복사한 새 연도 프로젝트를 비활성으로 만듭니다. 이름에 연도가 있으면 새 연도로 바뀝니다. 집행·거래처 규칙·저장한 뉴스레터는 복사되지 않습니다 |
| 「삭제」 | 비활성 프로젝트에만 있습니다. 「이 프로젝트를 삭제하시겠습니까? 복구할 수 없습니다.」 |
| 「활성 모듈 선택」 | 체크한 메뉴만 보입니다. 「💾 현재 구조 저장」은 전부 체크된 채, 「📥 엑셀 업로드」는 「🏫 학교관리」만 빠진 채 시작합니다. 「⚙️ 관리자」는 항상 보입니다 |

**주의**
- 활성 프로젝트는 모든 사용자에게 같습니다. 전환하면 다른 사람도 다음에 열 때 바뀐 예산 구조와 메뉴를 봅니다.
- 전환하면 예산관리·대시보드에는 그 프로젝트의 집행(과 프로젝트 없이 등록된 집행)만 나옵니다. 거래처 규칙·저장한 뉴스레터도 프로젝트별입니다. 일정·게시판·갤러리·학교·수급자·기관 정보는 모든 프로젝트가 함께 씁니다.
- 만든 프로젝트의 이름·예산 구조·모듈은 고칠 수 없습니다. 예산이 달라져 엑셀로 새 프로젝트를 만들어 활성화하면 그동안 등록한 집행은 옛 프로젝트에 남아 예산관리·대시보드에서 빠집니다. 연중 변경은 먼저 [13장](#13-현재-한계)을 보세요. 복제본도 예산액이 그대로입니다.
- 「💾 현재 구조 저장」은 지금 활성 프로젝트가 아니라 앱에 내장된 2026년 구조를 저장합니다.
- 엑셀 열 이름에 "내역"·"세부"가 들어가면 엉뚱한 열로 잡힐 수 있고(예: "산출내역"은 항목, "세부항목"은 소분류), 예산 열 이름이 "예산"·"금액"뿐이면 예산이 0원으로 들어갑니다.
- 프로젝트를 지우면 그 프로젝트의 거래처 규칙도 함께 지워집니다. 집행이 남은 프로젝트는 지우지 말고 비활성으로 두세요.
- 삭제가 서버에서 거부돼도 목록에서는 사라집니다. 새로고침한 뒤 다시 보이면 지워지지 않은 것입니다.

#### 4.9.5 활동 로그
<!-- src: renderAdmin#logs -->

**언제 쓰나** — 누가 언제 댓글을 달았는지, 집행내역을 일괄로 바꾸거나 지웠는지 확인할 때.

> **지금은 운영 환경에서 활동 로그가 저장되지 않습니다.** 서버의 기록 표와 앱이 쓰는 칸 이름이 달라 저장이 조용히 실패합니다. 그래서 이 탭과 대시보드 「🕐 최근 활동」은 비어 있습니다. 고치는 일은 따로 진행합니다([13장](#13-현재-한계)).

**기록되는 작업** — 고쳐진 뒤에도 아래 네 가지만 남습니다. 집행 한 건씩의 등록·수정·삭제·상태 변경, 일괄등록, 댓글 수정·삭제, 관리자 화면에서 바꾼 것, 로그인은 기록되지 않습니다.

| 기록 | 언제 남나 | 상세 |
|---|---|---|
| 「댓글 작성」 | 게시판·갤러리에 댓글을 달 때 | 댓글 앞부분 50자 |
| 「프로필 수정」 | 머리글의 이름을 눌러 프로필을 저장할 때 | 저장한 이름 |
| 「일괄 상태 변경」 | 집행내역 일괄 작업 줄의 「일괄 승인」「일괄 집행」「일괄 완료」 | 건수와 바뀐 상태. 상태는 영어로 나옵니다(approved 승인, executed 집행, completed 완료) |
| 「일괄 삭제」 | 일괄 작업 줄의 「일괄 삭제」 | 건수 |

**화면 요소**

| 요소 | 하는 일 |
|---|---|
| 기록 줄 | 작업 이름, 상세, 사람 이름(없으면 「시스템」), 날짜와 시각 |
| 「사용자 전체」 | 불러온 기록에 나오는 이름으로 거릅니다 |
| 「작업 유형 전체」 | 「등록」「수정」「삭제」「승인」「댓글」「프로필」「일괄」 중 고른 말이 기록 이름에 들어간 것만 보입니다. 「등록」「승인」에 맞는 기록은 만들어지지 않습니다 |
| 날짜 두 칸 | 시작일 ~ 종료일로 거르고, 오른쪽에 남은 건수 「…건」이 나옵니다 |
| 「🔄 새로고침」 | 가장 최근 기록 100건을 다시 불러옵니다 |
| 「로그 불러오기」 | 불러온 기록이 하나도 없을 때 「기록된 활동 로그가 없습니다.」와 함께 나옵니다 |

**주의**
- 가장 최근 100건만 불러옵니다. 그보다 오래된 기록은 필터로도 찾을 수 없습니다.
- 대시보드 「🕐 최근 활동」은 같은 기록의 최근 5건입니다. 그 「전체보기」는 관리자 화면의 마지막 탭을 여니 「📜 활동 로그」 탭을 다시 누르세요.
- 기록 저장이 실패해도 하던 작업은 그대로 끝나고 기록만 빠집니다. 안내는 뜨지 않습니다.

## 5. 입력 약속

화면마다 입력 칸은 달라도 아래 약속은 같습니다.

| 항목 | 약속 | 예 |
|---|---|---|
| 금액 | 숫자만 넣습니다. 쉼표는 저절로 붙고 숫자가 아닌 글자는 지워집니다. 원 단위 정수만 됩니다 | `330000` → 330,000 |
| 날짜 | 달력에서 고르거나 `YYYY-MM-DD`로 넣습니다. 은행 파일의 `2026.09.18 14:03`, `2026/9/8` 같은 표기는 자동으로 바뀝니다 | 2026-09-18 |
| 결제 방법 | 「카드」 또는 「계좌이체」만 고릅니다. 재단 지원금은 현금으로 지급하지 않습니다 | 계좌이체 |
| 수취인 | 증빙에 적힌 이름 그대로 씁니다. 자동배정은 (주)·㈜·주식회사·공백·괄호를 무시하므로 "㈜가나다인쇄"와 "가나다 인쇄"를 같은 거래처로 봅니다 | ㈜가나다인쇄 |
| 집행 내용 | 무엇을·얼마나·왜를 한 줄로 씁니다. 보고서와 엑셀에 그대로 나갑니다 | 9월 캠페인 리플릿 인쇄 500부 |
| 증빙 파일 | 「📄 필요 증빙서류」·「필요 증빙서류:」 목록에서 서류마다 「📎 첨부하기」로 붙입니다. 입금확인증 PDF로 등록한 건은 이체 증빙이 자동으로 붙습니다 | 수령확인증, 이체확인증 |

**집행 상태 4단계**

집행은 등록하면 「대기」로 시작합니다. 상태는 집행내역에서 바꿉니다([4.2.7](#427-집행내역)).

| 상태 | 뜻 | 보고서에 |
|---|---|---|
| 「대기」 | 등록만 한 상태. 확인이 필요함 | 들어가지 않음 |
| 「승인」 | 집행해도 된다고 확인함 | 들어감 |
| 「집행」 | 돈을 지급함 | 들어감 |
| 「완료」 | 증빙까지 갖춰 정산 준비가 끝남 | 들어감 |

> 대시보드는 「대기」 건이 있으면 「미승인 집행건 …건 처리 필요」로 알려 줍니다. 예산 소진율 경고에는 「대기」 건도 포함됩니다.

## 6. 알림·표시 읽는 법

**대시보드 알림 4종** — 🔴 긴급 → 🟠 주의 → 🔵 안내 순으로 5개까지 보입니다. 재단 마감 알림은 5개 안에 들지 않아도 늘 보입니다.

| 알림 | 화면 문장 | 뜨는 조건 | 단계 |
|---|---|---|---|
| 일정 | 「[D-…] … (…)」 = 남은 날 · 일정 제목 · 시작일 | 앱 일정의 시작일이 7일 안(취소 일정 포함, Google 일정 제외). 당일은 D-Day | 1일 이내 🔴, 3일 이내 🟠, 그 밖 🔵 |
| 미승인 집행 | 「미승인 집행건 …건 처리 필요」 | 「대기」 상태 집행이 1건 이상 | 🟠 |
| 재단 마감 | 「[D-…] … (…)」 = 남은 날 · 마감 이름 · 날짜 | 재단 마감 5건 가운데 30일 안에 있는 것 ([9장](#9-레퍼런스)). 당일은 D-Day | 3일 이내 🔴, 7일 이내 🟠, 그 밖 🔵 |
| 예산 소진 | 「… 예산 소진율 …%」 | 소분류 집행액(「대기」 포함) ÷ 소분류 예산이 85% 이상 | 95% 이상 🔴, 그 밖 🟠 |

- 오른쪽 ×로 닫은 알림은 이 브라우저 탭을 닫을 때까지 다시 뜨지 않습니다. 새 탭에서 열면 다시 보입니다.
- 미승인 알림은 닫은 뒤 건수가 늘어도, 소진 알림은 85%에서 95%로 올라도 같은 탭에서는 다시 뜨지 않습니다.
- 소진 기준은 화면마다 다릅니다: 알림은 85%·95%, 「⚖️ 카테고리별 과부족 현황」은 80%·100%, 대시보드 집행 막대 색은 80%·100%(예산 대시보드는 50%·90%, 비용비율은 70%·90%).

**일괄등록 미리보기 표시**

| 표시 | 뜻 |
|---|---|
| 「출금」「입금」「수수료」 | 행의 종류. 입금 행은 지출이 아니므로 자동배정하지 않습니다 |
| 「📌 규칙」「🕘 이력 …회」「❓ 미배정」 | 항목을 거래처 규칙으로 / 같은 수취인의 과거 집행(…회)으로 채웠음 / 채우지 못했음 |
| 「후보 …개 ▾」 | 과거 항목 후보. 후보가 여럿이거나 한 번뿐이라 자동으로 정하지 않았을 때 |
| 「⚠ 중복 의심 (기존 … · …)」 | 이미 등록된 집행(일자 · 금액)과 짝지어짐. 처음엔 체크가 꺼져 있음 |
| 「⚠ …」 | 「텍스트 없음(스캔본)」「업로드 내 중복」, 날짜·금액·수취인을 못 읽음 등 |
| 「📎 PDF …/…쪽」 | 이 행에 증빙으로 붙을 PDF 쪽 |
| 「본 행 항목 연동」 / 「항목 직접 지정」 | 수수료 행이 본 행 항목을 따라감 / 직접 바꿔 연동이 풀림 |
| 흐린 행 | 체크가 꺼져 등록되지 않는 행 |

**집행내역 표시**

| 표시 | 뜻 |

| 「증빙서류 미비 …건」 | 필요 서류 가운데 빈 칸이 있는 집행 건수(전체 기준). 대안 서류까지 세므로 실제보다 많을 수 있음 |

## 7. 데이터 구조

예산은 네 단계로 내려가고, 집행 한 건에 증빙 파일이 여러 개 붙습니다.

```
프로젝트 (한 번에 하나만 활성)
 └─ 예산 구조 ─ 사업비 / 운영비
     └─ 소분류 (예: 사업인건비, 사업홍보비)
         └─ 항목 (예: 자문료, 리플릿 인쇄)
             └─ 집행 (집행일 · 금액 · 수취인 · 결제 방법 · 집행 내용 · 상태)
                 └─ 증빙 파일 (수령확인증 · 이체확인증 · 영수증 …)
```

**어디에 저장되나**

거의 모든 데이터는 서버(Supabase 데이터베이스와 첨부 저장소)에 저장됩니다. 어느 컴퓨터·휴대폰에서 로그인해도 같은 내용이 보입니다.

| 데이터 | 저장 위치 | 쓰이는 곳 |
|---|---|---|
| 프로젝트·예산 구조·메뉴 구성 | 서버 | 모든 예산 화면, 메뉴 |
| 집행 | 서버 | 예산관리, 대시보드, 보고서 |
| 증빙·게시판 첨부·사진 파일 | 서버 첨부 저장소 | 집행내역, 게시판, 갤러리, 뉴스레터 |
| 거래처 규칙 | 서버 | 자동배정 ([4.2.5](#425-거래처-규칙)) |
| 수급자 | 서버 | 급여지급명세서의 생년월일·주소 ([4.9.2](#492-수급자-관리)) |
| 기관 정보·직인 이미지 | 서버 | 급여지급명세서·회의진행일지·사업변경신청서 (직인은 화면·PDF 서식만) ([4.9.3](#493-기관-정보)) |
| 일정 | 서버 | 일정관리, 대시보드 |
| 출석 기록 | 서버와 이 브라우저 양쪽 | 출석부, 대시보드 참여율 (지금은 쓰이지 않음, [13장](#13-현재-한계)) |
| 게시글·댓글 | 서버 | 게시판, 뉴스레터 |
| 뉴스레터 초안 | 서버 | 뉴스레터 |
| 학교·교과서 | 서버 | 학교관리 |
| 사용자·활동 로그 | 서버 | 관리자 |
| 로그인 상태 | 이 브라우저 (24시간) | — |
| 닫은 알림 | 이 브라우저 탭 (탭을 닫을 때까지) | 대시보드 |
| Google 캘린더 연결 | 이 화면의 메모리 (새로고침하면 풀림) | 일정관리 |

- **소분류·항목은 프로젝트의 예산 구조를 따릅니다.** 프로젝트를 바꾸면 예산 화면의 분류도 바뀝니다([4.9.4](#494-프로젝트-관리)).
- **집행 한 건에는 예산 분류가 함께 기록됩니다.** 그래서 집행내역·보고서·엑셀에 소분류와 항목 이름이 그대로 나옵니다.
- **증빙은 집행 건에 붙습니다.** 집행을 지우면 그 건에 붙은 첨부 기록도 함께 지워지고, 되살릴 수 없습니다.

| 급여명세서 묶음 | 「📦 급여명세서 일괄」 | 수취인별 HTML 파일을 묶은 ZIP | 운영인건비 전체 |

| 회의진행일지 | 행의 「📋 회의진행일지 생성」 → 「📝 HWPX 다운로드」 / 「📋 문서 생성」 | 재단 서식 HWPX(참석자 6명마다 1장) / 새 창 인쇄 | 창에 넣은 회의 1건 |
| 사업변경신청서 | 「📝 사업변경신청서」 → 「📝 문서 생성」 | 새 창 → 「🖨️ 인쇄 / PDF 저장」 | 창에 넣은 내용 (앱에 저장되지 않음) |

- 한글(HWPX) 파일은 서버에서 만들므로 인터넷이 필요합니다. 여러 장이 되면 ZIP으로 받습니다.
- 새 창으로 여는 출력물은 팝업이 막혀 있으면 열리지 않습니다. 특히 「📄 정산보고서」「📋 월별 명세서」는 막혀도 아무 안내가 없습니다.
- 보고서의 행은 집행일순이 아니라 최근 등록순입니다.
- 사업기획 도구(`/kihoek learn --kind summary`)에 넘길 엑셀은 「🔄 초기화」로 필터를 모두 푼 뒤 「📊 Excel 내보내기」로 받습니다.

| 출력물 | 어디서 | 형식 | 범위 |
|---|---|---|---|
| 대시보드 인쇄 | 「🏠 대시보드」 「🖨️ 인쇄」 | 브라우저 인쇄("PDF로 저장" 가능) | 화면 그대로(메뉴·버튼 제외) |
| 대시보드 스냅샷 | 「📸 HTML 스냅샷」 | `대시보드_스냅샷_날짜.html` | 대시보드 본문 |

## 9. 레퍼런스

**집행 상태** — 「대기」(보고서에서 빠짐) → 「승인」 → 「집행」 → 「완료」. 뜻은 [5장](#5-입력-약속), 바꾸는 곳은 [4.2.7](#427-집행내역).

**원천징수 기준** (「🧮 원천징수계산」이 쓰는 값 — 강사료 같은 기타소득용이며, 운영인건비 급여와 급여지급명세서에는 쓰이지 않습니다)

| 항목 | 값 |
|---|---|
| 떼는 기준 | 같은 사람에게 하루에 지급한 합계가 125,000원을 넘을 때 (수행가이드 p.14). 계산기는 입력한 금액 한 건으로 판단하므로, 같은 날 여러 번 지급했다면 합계를 넣어 확인합니다 |
| 소득세 | 지급액의 8%, 원 단위 아래 버림 |
| 지방소득세 | 소득세의 10%, 원 단위 아래 버림 |
| 실지급액 | 지급액 − 소득세 − 지방소득세 |
| 예 | 강사료 210,000원 → 소득세 16,800원 + 지방소득세 1,680원 = 18,480원, 실지급액 191,520원 |

이 값은 필요경비 60%인 기타소득(강사료·자문료 등) 기준입니다. 상금이나 일용근로처럼 다른 소득은 [4.2.6](#426-원천징수계산)을 보세요.

**계정 유형 12개** — 예산 항목마다 계정 유형이 정해져 있어서, 집행할 때 항목을 고르면 유형이 따라옵니다. 유형마다 필요한 증빙이 다르며, 집행등록 화면의 「📄 필요 증빙서류」와 「📖 회계가이드」 → 「📂 계정항목별 안내」에서 확인합니다.

임차료(사무실 임대료)와 예비비 항목은 앱에 증빙 규칙이 없어 「📄 필요 증빙서류」가 비어 보입니다. 이 두 항목은 「📂 계정항목별 안내」의 설명을 보고 서류를 갖춥니다.

## 10. 개인정보·재단 규정 안전장치

| 장치 | 내용 |
|---|---|
| 계좌번호를 집행 기록에 옮기지 않음 | 입금확인증 PDF의 출금·입금 계좌번호는 읽는 중에만 쓰고 집행 기록·화면·로그에 남기지 않습니다. 증빙으로 붙는 PDF 원본에는 은행이 찍은 번호가 그대로 있으니, 증빙 파일을 밖으로 보낼 때 주의합니다 |
| PDF 글자 읽기는 브라우저 안에서 | 입금확인증의 내용 추출은 이 컴퓨터에서 끝납니다. 서버로 올라가는 것은 증빙으로 붙이는 PDF 파일뿐입니다 |
| 비밀번호는 해시로만 저장 | 서버에는 비밀번호 원문이 아니라 변환값(SHA-256)만 저장합니다 |
| 한글(HWPX) 서식 만들기 | 서식에 넣을 이름·금액·생년월일·주소를 서버 함수로 보내 파일을 만들어 받습니다. 인터넷이 필요합니다 |
| 게시글 비밀번호 | 관리자가 아닌 사람이 게시글을 고치거나 지우려면 글쓴이가 정한 비밀번호가 필요합니다 |
| 관리자 전용 기능 | 관리자 메뉴, 집행 한 건씩 지우기·상태 바꾸기, 학교 등록·수정 등은 관리자만 합니다 ([9장](#9-레퍼런스) 역할 표) |
| 활동 로그 | 댓글 작성, 프로필 수정, 집행 일괄 상태 변경·일괄 삭제를 기록하도록 만들어져 있지만, 지금은 운영 환경에서 저장되지 않습니다 ([4.9.5](#495-활동-로그)) |
| 매뉴얼 | 이 문서에는 계정·연락처·실명·계좌가 없습니다. 웹 주소로 누구나 열 수 있는 파일이기 때문입니다 |

**사람이 지킬 것**

- **수급자 정보**(생년월일·주소·전화)는 급여지급명세서에 필요한 사람만 등록합니다. 필요 없어지면 「수정」에서 생년월일·주소·전화번호를 비워 「수정 저장」한 뒤 「삭제」합니다. 「삭제」는 목록에서 숨기기만 합니다.
- **학교 실명**은 앱 안(학교관리)에서만 씁니다. 뉴스레터·홍보물처럼 밖으로 나가는 글에는 "OO 소재 반도체고"처럼 지역+유형으로 씁니다.
- **재단 표기**: '후원'이 아니라 '지원'으로 쓰고, '아름다운재단'은 붙여 씁니다. 홍보물은 배포 전에 재단 담당자에게 지원처 표기를 확인합니다.
- **열람자 계정**도 집행 등록·수정과 일괄 작업을 할 수 있습니다. 재단 담당자 등 외부인에게 계정을 줄 때 이 점을 알고 주세요([4.9.1](#491-사용자-관리)).
- **함께 쓰는 컴퓨터**에서는 일을 마치면 「로그아웃」을 누릅니다. 로그인은 24시간 유지됩니다.

## 12. 문제 해결

| 증상 | 원인 | 해결 |
|---|---|---|
| 화면이 하얗게 비어 있음 | 화면을 그리는 도구를 불러오지 못함(인터넷 끊김 등) | 새로고침. 계속되면 다른 브라우저로 열어 보고 개발 담당자에게 알림 |
| 다음 날 열었더니 로그인 화면이 나옴 | 로그인은 로그인한 때부터 24시간 유지 | 다시 로그인. 오래 열어 둔 창은 입력을 먼저 저장한 뒤 새로고침 |
| 「⚙️ 관리자」 메뉴가 없음 | 관리자 역할이 아니거나, 역할을 바꾼 뒤 옛 로그인을 쓰는 중 | 로그아웃 후 다시 로그인. 그래도 없으면 관리자에게 역할 확인 |
| 「📎 입금확인증 PDF로 자동입력」이나 일괄등록 「파일 선택」이 눌리지 않음 | PDF 읽기 도구를 아직 불러오지 못함 | 새로고침, 인터넷 연결 확인 |
| PDF를 올렸더니 값이 비어 있음 | 스캔본이거나 신한은행이 아닌 양식 | 직접 입력(증빙은 붙음), 인터넷뱅킹에서 PDF로 다시 저장 |
| 새 건인데 「⚠ 중복 의심」으로 체크가 꺼짐 | 같은 일자·금액·수취인의 집행이 이미 있음 | 집행내역에서 확인한 뒤 체크를 켜고 등록 |
| 「✅ …건 일괄 등록」 숫자보다 적게 등록됨 | 예산항목을 고르지 않은 행은 건너뜀 | 「소분류」「예산항목」 지정 후 다시 |
| 본 행을 뺐는데 수수료 행이 등록됨 | 수수료 행의 체크는 따로 | 수수료 행 체크도 끄기. 이미 등록됐으면 집행내역에서 정리 |
| 엑셀 미리보기의 금액이 0이거나 출금·입금 구분이 틀림 | 열 자동 선택이 틀림(출금·입금 금액이 나뉜 양식 등) | 「금액」에 출금 열을 고르고 「입금/출금 구분」은 비우기. 이때는 모든 행이 「입금」으로 보이지만 자동배정은 되므로 입금 거래 행만 체크를 끄기 |
| 「❓ 미배정」이 많음 | 규칙이 없고 이력이 1회뿐이거나 항목이 여럿 | 「후보 …개 ▾」에서 고르거나 직접 고르고 「규칙 저장」 |
| 「📄 필요 증빙서류」 목록이 비어 있음 | 임차료·예비비처럼 증빙 규칙이 없는 계정 | 「📖 회계가이드」 「📂 계정항목별 안내」에서 서류 확인 |
| 「증빙서류 미비」 건수가 줄지 않음 | 대안 서류·해당할 때만 내는 서류까지 셈 | 실제 필요한 서류만 붙이고 건수는 참고 |
| 잘못 붙인 증빙을 바꾸거나 지우고 싶음 | 앱에 바꾸기·지우기 버튼이 없음 | 개발 담당자에게 요청 |
| 보고서에 몇 건이 빠짐 | 「대기」 건은 보고서에서 빠짐 | 승인(또는 일괄 승인) 후 다시 출력 |
| 엑셀에 「대기」 건이 섞임 | 엑셀은 지금 화면 필터를 그대로 따름 | 상태 필터를 고르거나 필요한 건만 체크해 「📥 선택 내보내기」 |
| 「📄 정산보고서」를 눌러도 아무 일이 없음 | 팝업 차단(안내 없음) | 이 사이트의 팝업 허용 후 다시 |
| 일괄 승인했더니 화면에 안 보이던 건까지 바뀜 | 필터를 바꿔도 체크가 남음 | 일괄 작업 전에 「✅ …건 선택」 건수 확인, 필요하면 「선택 해제」 |
| 급여지급명세서 생년월일·주소가 빈칸 | 수급자 미등록, 또는 이름이 수취인과 다름 | 「📋 수급자 관리」에서 「성명 *」을 수취인과 똑같이 |
| 대시보드 금액이 정산보고서와 다름 | 대시보드·비용비율은 「대기」 포함, 보고서는 승인 이후만 | 정상. 상태를 정리한 뒤 비교 |
| 대시보드 요약 카드 숫자가 그대로 | 카드는 처음 불러올 때만 계산 | 새로고침 |
| 「Google Calendar 연결」을 눌러도 창이 안 뜸 | 브라우저가 Google 로그인 팝업을 막음 | 팝업 허용 후 다시 |
| 새로고침했더니 Google 일정이 사라짐 | Google 연결은 화면을 연 동안만 유지 | 다시 연결 |
| Google 캘린더에 같은 일정이 여러 개 | 「전체 동기화」를 여러 번 누름 | Google 캘린더에서 지우고, 전체 동기화는 한 번만 |
| 사진이 「허용되지 않는 파일 형식입니다.」로 거부됨 | 아이폰 HEIC, 동영상, HWPX | JPG·PDF로 바꿔 올리기 |
| 글 「등록」 버튼이 회색 | 제목·내용·비밀번호(갤러리는 제목·비밀번호) 중 빈 칸 | 빈 칸 채우기 |
| 지난 호 뉴스레터 내용이 바뀌어 있음 | 「불러오기」 뒤 고쳐 「💾 임시저장」 → 덮어쓰기 | 다음 호는 「복제」로 시작 |
| 「🏫 학교관리」 메뉴가 없음 | 활성 프로젝트에 학교관리 모듈이 없음 | 관리자가 모듈을 켠 프로젝트를 활성화 |
| 학교 상세에 「📅 시간표」가 없음 | NEIS로 고르지 않고 직접 입력한 학교 | 「✏️ 수정」 → 「🔍 NEIS 검색」으로 골라 저장 |
| 프로젝트를 바꿨더니 집행이 사라짐 | 집행은 프로젝트별로 보임 | 옛 프로젝트를 다시 「활성화」하면 보임 |
| 「서식 생성 서버 연결 실패. 잠시 후 다시 시도해주세요.」 | 인터넷이 끊겼거나 서식 서버에 연결하지 못함 | 연결을 확인하고 다시 「📥 생성 및 다운로드」(회의진행일지는 「📝 HWPX 다운로드」) |
| 급여지급명세서 지급자 칸(대표자·고유번호·주소)이 빈칸으로 나옴 | 「🏢 기관 정보」가 비어 있음 (기관명은 비워도 '청년노동자인권센터'가 들어감) | 「기관정보 설정으로 이동」 → 입력 → 「💾 저장」 후 다시 만들기 |
| 화면 위에 「📡 오프라인 상태 — 인터넷 연결을 확인해주세요」가 뜸 | 인터넷이 끊김 | 다시 연결되면 앱이 저절로 새로고침합니다. 저장하지 않은 입력은 사라지니 끊긴 동안 새로 입력하지 마세요 |
| 도움말에 「매뉴얼을 불러오지 못했습니다.」가 뜸 | 인터넷이 끊겼고 전에 열어 둔 적도 없음 | 연결 뒤 「다시 시도」 |
| 도움말에 「서식 없이 원문으로 보여 줍니다.」가 뜸 | 서식 도구를 불러오지 못함 | 내용은 같습니다. 서식이 필요하면 연결 뒤 새로고침 |

## 13. 현재 한계

2026-10-02 기준입니다. 고치기 전까지는 오른쪽 "대신 할 일"로 피해 가세요.

| 영역 | 한계 | 대신 할 일 |
|---|---|---|
| 일괄등록 | 입금확인증 PDF는 **신한은행 양식만** 검증됨. 다른 은행은 값이 비거나 틀릴 수 있음 | 미리보기에서 고치거나 은행 거래내역 엑셀로 등록 ([4.2.4](#424-일괄등록)) |
| 일괄등록 | 스캔한 PDF·사진은 **글자 인식(OCR)이 없음** — 「텍스트 없음」 경고만 나옴 | 값을 직접 입력 (증빙은 붙음) |
| 일괄등록 | 은행 엑셀 행은 **중복·날짜·금액 검사를 하지 않음** | 이미 등록한 거래, 0원 행은 체크를 끄기 |

| 증빙 | 필요 서류 목록이 결제 방법을 가리지 않고 대안 서류까지 보여 「증빙서류 미비 …건」이 실제보다 많음. 임차료·예비비는 목록 자체가 없음 | 실제 필요한 서류만 붙이고 건수는 참고로 ([4.2.7](#427-집행내역)) |
| 예산 편성 | 만든 프로젝트의 **편성은 고칠 수 없음**. 바꾸려면 엑셀로 새 프로젝트를 만들어야 하고, 그러면 기존 집행·거래처 규칙과 연결이 끊김 | 사업변경 승인 뒤에만, 전환 전에 출력물 확보 ([4.2.2](#422-예산편성표), [4.9.4](#494-프로젝트-관리)) |
| 예산 편성 | 상반기·하반기 구분 날짜가 **2026년으로 고정** | 다른 연차에서는 전체 기간으로 보기, 갱신 요청 |
| 원천징수 | 「🧮 원천징수계산」은 **필요경비 60% 기타소득 식 하나**. 상금(80%)·일용근로(근로소득)는 결과가 다르고, 125,000원 기준을 한 건으로만 판단 | 「📖 회계가이드」 계산기나 세무 확인, 같은 날 합계로 판단 ([4.2.6](#426-원천징수계산)) |

| 게시판 | 운영 사이트에서는 링크 미리보기에 **제목·그림 없이 주소만** 나옴 | 링크는 정상으로 열림 |

| 화면 | 휴대폰 폭에서 대시보드의 일부 금액 칸이 **화면 밖으로 넘침** | 큰 화면에서 확인 |
